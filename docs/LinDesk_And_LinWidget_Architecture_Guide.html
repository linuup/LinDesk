LinDesk & LinWidget 架构与开发技术指南

本文档作为后续长期维护、扩展 LinWidget 组件系统以及深入理解 LinDesk 桌面底座的单一事实源（Single Source of Truth）。全文基于真实代码逐行分析提炼，杜绝模糊推测。

1. 系统总体定位与技术栈

LinDesk 是一款面向 Windows 平台的高性能桌面整理与小组件增强宿主软件。它融合了传统的桌面栅格收纳（Fences 式收纳盒子 LinBox）与基于现代 Web 技术的桌面组件渲染引擎（LinWidget）。

技术层次 采用技术 / 库 职责定位
宿主核心 (Core) C++17, Qt 5.15.2, CMake, vcpkg 进程生命周期、Win32 桌面宿主嵌入、事件调度、托盘控制。
桌面交互 (Desktop) Qt Widgets, GDI/Direct2D 全屏透明画布、图标网格排布、框选逻辑、右键菜单、LinBox 栅格盒子。
组件运行时 (LinWidget) Microsoft WebView2 (Chromium 引擎) 单实例独立宿主，运行在桌面层与图标层之间，渲染富交互小组件。
组件生态 (Widgets) HTML5, Vanilla CSS, Modern JavaScript 10 个内置组件（时钟、监控、天气、便签、风扇、待办等），零外部臃肿依赖。

2. 桌面底座与原生三层架构

2.1 Z-Order 叠放模型（真实窗口堆叠链）

LinDesk 之所以能够实现「组件既可以响应交互，又不会遮挡桌面图标框选」，依赖于其精确控制的 Win32 原生窗口层次：

顶层：桌面交互层 (ListView / LinBox) Qt5 QWidget (WinId / HWND)
ListView
桌面原生文件/快捷方式图标、鼠标框选绘制 (SelectArea)、桌面全局右键菜单。
LinBox (收纳格子)
可折叠、可拉伸的图标分类管理容器，支持拖拽放置 (Ghost Drop)。
▼ Z-Order: 组件宿主严格置于 ListView 之下 (SetWindowPos / Sibling) ▼
中间层：LinWidget 共享运行时宿主 (WebView2) Qt5 QWindow / WebView2 Controller
LinWidgetWebViewRuntime
运行 host.html 单一画板；各组件通过 panel 容器排布在全屏透明 WebView2 内部。
syncWidgetWindowLayer()
通过 Win32 API 动态将自身 HWND 插入到 ListView 窗口正下方，保证层级稳定。
▼ Z-Order: 壁纸底座窗口位于最底层 ▼
底层：桌面壁纸与挂载底座 (LinDesktop) WorkerW / Progman 子窗口
LinDesktop::paintEvent
静态壁纸平滑过渡渲染（双重 QPixmap 透明度动画混合），无鼠标事件拦截。
动态壁纸 (可选)
LinWallpaperWebViewRuntime 独立 WebView2 窗口，支持 HTML5 视频/Web 动态壁纸。

2.2 Win32 WorkerW 挂载机制

在 src/desktop/LinDesktop.cpp 中，通过 Windows 未公开的桌面挂载技术实现嵌入：

  1. 向 Progman 窗口发送 0x052C 消息（WM_ERASEBKGND 特殊调用），促使 Windows 系统桌面管理器拆分出专门的 WorkerW 窗口。
  2. 寻找位于 SHELLDLL_DefView（系统原生桌面图标容器）下方的 WorkerW 实例句柄。
  3. 调用 Win32 SetParent(linDesktopHwnd, workerWHwnd)，将 LinDesktop 设置为其子窗口，实现与 Windows 系统原生桌面同生共灭，不被 Win+D 最小化打扰。

2.3 防抢占与自愈机制

为防止第三方壁纸软件（如 Wallpaper Engine、Lively）或动态桌面管理工具重启 Explorer 导致窗口丢失：

  • LinDesktop 启用了桌面宿主窗口监听（startDesktopHostWindowMonitor），监测 EVENT_OBJECT_CREATE 与 EVENT_OBJECT_DESTROY。
  • 一旦检测到层级脱落，触发 scheduleLinWidgetLayerRecovery()，重新执行 WidgetManager::syncWidgetWindowLayer()，将 WebView2 窗口重新拉回到桌面正确层级。

3. LinWidget 组件系统（核心维护重点）

核心设计思想：单 WebView2 共享宿主 (Shared Host Model)

在旧版本构想中，可能存在「每个组件单独开一个进程或独立窗口」的设想；但在真实代码中，LinWidget 采用的是极其高效的单实例共享宿主（Single WebView2 Shared Host）： 内存中仅运行一个 Chromium 渲染进程，加载 host.html；所有桌面小组件均作为子面板（Panel）呈现在宿主内。这使得 10 个小组件同时运行时的内存占用降低了 80% 以上！
