1. 背景与核心定位

LinDesk 组件平台的定位是极致轻量的桌面开放式纯 Web 容器：任何标准的 HTML/CSS/JS 页面都能无缝成为桌面小组件或动态壁纸。组件系统作为独立动态库（LinWidgetRuntime.dll）运行在主进程内，按需挂载，零捆绑、零冗余侵入。已实现

创作者画像（面向真实人类开发者）：

  • 零 C++ 依赖：懂 HTML/CSS/JS 的普通前端开发者即可开发，无需配置任何 C++ 编译环境或构建工具链；
  • 零多余 SDK 与私有 API：不搞复杂的专有 RPC 协议与繁重 SDK，网页数据直接用 localStorage，网络直接用 fetch，图形动画直接用 Canvas/WebGL；
  • 极简系统能力补足：宿主仅提供三合一全局对象 window.LinDesk，仅负责补足浏览器缺失的“硬件指标监测、安全定位文件/网页、容器控制”三类原生能力；
  • 视觉与实现 100% 自由：不设强制设计令牌或预设样式库，UI 表现完全由创作者自主决定。

2. 系统架构、全流程拓扑与目录存储隔离

2.0 组件系统全流程闭环拓扑与六大核心管道

LinDesk 组件系统打通了从底层二进制装载、磁盘包分流、多层像素混流到原生能力注入与全屏休眠的完整闭环，由六大管道协同运行：

核心管道系统职责与内部机制用户体验与交付价值
1. 运行时装载流
(Runtime Lifecycle)		 主程序与 CEF 零静态依赖；LinWidgetRuntime.dll 按需 LoadLibrary；支持在线下载进度条、离线 zip 安装、SHA-256 校验与无重启动态卸载。 未安装时 0 额外进程、0 显存占用，底座纯绿色秒开；随时安全启停与更新。
2. 包管理与分流流
(Package & Routing)		 统一 .lw 格式；安装器按 type 自动分流解压至 LinWidgets/（组件）与 Wallpapers/（壁纸）；开发期支持明文文件夹直接放入热读取。 壁纸与组件物理级彻底解耦，彻底消灭历史混放与目录混乱。
3. 四层图层混合流
(Compositing & Layers)		 单条 QPainter 绘制管线无窗口句柄叠加：Layer 0（系统底层）→ Layer 1（壁纸层，CEF OSR 全屏）→ Layer 2（桌面图标与 LinBox 容器）→ Layer 3（桌面小组件）→ Layer 4（交互框选与 Ctrl 手柄）。 杜绝 Windows DWM 子窗口闪烁与白屏，像素级支持 Alpha 透明通道与亚克力混流。
4. 交互穿透与仲裁流
(Input Arbitration)		 小组件遵循「Ctrl 键宿主编排（8 方向缩放/平移/滚轮等比缩放）」与「免 Ctrl 原生交付（透明区域穿透，不透明区域点击）」；全屏壁纸与图标框选执行「6px 曼哈顿位移仲裁」。 壁纸粒子互动丝滑，桌面拉框选图标零冲突，组件内部网页按钮/输入框 100% 原生响应。
5. 原生注入与数据流
(window.LinDesk)		 每个组件与壁纸以 linwidget://<id>/ 独占 Origin，天然获得 Chromium 隔离的 localStorage/IndexedDB；宿主仅注入 window.LinDesk（system 硬件监控、shell 资源管理器安全定位、widget 容器控制、wallpaper 参数同步）。 普通能力直接使用原生 Web 标准；数据永不污染 LinDesk 宿主；杜绝恶意二进制拉起。
6. 能耗治理与熔断流
(Suspension & Fault)		 前台独占运行 3D 游戏（如 CS2、赛博朋克 2077）或视频放映时，宿主检测后立即调用 WasHidden(true) 挂起渲染管线与媒体解码（CPU/GPU 0.0%）；前台发声自动静音；单组件 60s 内累计崩溃 3 次触发熔断保护。 绝对不抢占前台生产力与游戏算力；避免宿主陷入死循环崩溃风暴。

2.1 运行时拆分与数据隔离红线 已落地

组件系统已完全拆分为 LinWidgetRuntime.dll（独立 SHARED 目标，含 WidgetManager / CEF OSR / 组件包加载器），经 RuntimeInstaller 安装到 <userData>/runtime/linwidget/ 并 LoadLibrary 动态加载；主程序经 C 导出接口判空调用，未安装时无组件代码、可独立编译运行。设置页可安装/卸载/更新运行时，全程不重启主程序。

数据隔离三条硬约束（验收红线）：

  1. 安装/卸载/更新只操作 <userData>/runtime/linwidget/ 与 config.ini 组件系统段；
  2. 图标/box 数据（data.dat|data.json 及 .tmp/.bak）绝不被组件系统任何流程读写；
  3. BoxManager / LayoutPersistenceService / DesktopItemLoader 留在主程序，不迁入运行时 DLL。

2.2 目录分流与统一 .lw 包规范（已落地实装）

为彻底消灭“壁纸与组件混放导致开发混乱”的历史痛点，系统确立统一包格式、严格目录物理分流机制：

  • 统一归档格式：小组件与动态壁纸均使用 .lw 标准 zip 压缩包格式；
  • 安装器智能分流：安装器解压前读取 manifest.json 中的 type 字段：
    • type: "widget" → 自动归档解压至 LinWidgets/<id>/ 目录，并在桌面组件层管理；
    • type: "wallpaper" → 自动归档解压至 Wallpapers/<id>/ 目录，并在壁纸工坊 (LinDesk Hub) 管理；
  • 开发期明文文件夹直读：创作者直接在 LinWidgets/ 或 Wallpapers/ 下新建文件夹即被识别，无需繁琐打包即可启动调试。

2.3 Chromium 域隔离存储机制（零私有 API） 已实现

宿主注册自定义本地资源协议 linwidget://：

  • 每个小组件以 linwidget://<id>/ 作为独立 Origin（域）；
  • 每个动态壁纸以 linwidget://wallpaper-<id>/ 作为独立 Origin；
  • 天然数据沙箱：Chromium 内核自动为每个独立域分配独立的 localStorage、IndexedDB 与 Cache 存储配额，不同组件之间、组件与壁纸之间数据物理隔离，完全不需要宿主实现任何私有存储 IPC。

5. 运行层：安全沙箱、敏感限制与生命周期休眠

5.1 openPath 物理级只读定位与外链协议限制

用户弹窗无法从根本上防止恶意操作，系统在底层对原生操作执行物理级硬限制：

  • 禁止任何二进制直接执行：LinDesk.shell.openPath(target) 在底层使用 SHOpenFolderAndSelectItems 或仅调用资源管理器浏览目录；凡是目标扩展名为 .exe、.bat、.cmd、.ps1、.vbs、.msi、.com 等可执行文件，宿主直接拒绝执行并返回 false，物理杜绝恶意组件静默唤起外部木马或病毒程序；
  • 外链协议严格白名单：LinDesk.shell.openUrl(url) 仅允许标准 http:// 与 https:// 协议，严格拦截 file://、javascript:、系统特权 URI（如 ms-settings:）等高危协议。

5.2 目录穿越防护 (Path Traversal Protection)

在 CEF 自定义 Scheme（linwidget://）资源加载器中，严格对请求相对路径进行规范化解析（QDir::cleanPath），强行阻断包含 ../ 或绝对盘符路径的越权资源请求，严禁组件包访问包目录以外的系统敏感文件。

5.3 智能功耗与休眠状态机（阶段一落地工程规范）

成熟动态壁纸的核心生死线在于极致性能与零负担体验。桌面壁纸绝不能与前台 3D 游戏、生产力工作争抢 GPU/CPU 算力，更不能在笔记本电池模式下引发风扇狂转或异常耗电。系统构建五重状态机（WallpaperPowerState）与四大检测子系统协同治理：

5.3.1 五重运行状态模型 (Power State Matrix)

5.3.2 四大检测子系统与核心技术选型

  • 全屏与独占 3D 游戏检测 (FullscreenDetector)：
    1. 监听 Windows 系统的 EVENT_SYSTEM_FOREGROUND 钩子及 1000ms 定期低频采样 GetForegroundWindow()；
    2. 严格排除任务栏（Shell_TrayWnd）、桌面底层（Progman/WorkerW）以及 LinDesk 自身窗口；
    3. 比对窗口矩形 GetWindowRect(hwnd) 与主屏幕物理分辨率 GetMonitorInfo()，当覆盖全屏时触发判定；
    4. 辅以 Windows Shell 原生 API SHQueryUserNotificationState() 双重校验：当处于 QUNS_RUNNING_D3D_FULL_SCREEN 或 QUNS_PRESENTATION_MODE 时直接判定为 3D 游戏独占或演示模式。
  • 最大化全遮挡检测 (OcclusionDetector)：
    1. 检测当前前台窗口是否携带 WS_MAXIMIZE 样式且非最小化；
    2. 计算其工作区覆盖率，当桌面已被 100% 遮挡且用户正专注前台办公时触发挂起，切回桌面时即刻 0 延迟恢复。
  • 笔记本电池模式与电源感知 (BatteryStatusMonitor)：
    1. 注册主窗口 WM_POWERBROADCAST 消息（PBT_APMPOWERSTATUSCHANGE）；
    2. 调用 Win32 GetSystemPowerStatus(&sps)，sps.ACLineStatus == 0 时自动切入 RunningThrottled（限 30 FPS），插入电源恢复 60 FPS；
    3. 向网页下发 window.LinDesk.wallpaper.onPowerStateChange({ onBattery: true, fpsLimit: 30 })。
  • 跨进程音频智能避让 (AudioDuckingMonitor)：
    1. 利用 Windows Core Audio API（IAudioSessionManager2 / IAudioSessionEnumerator）监听扬声器活动音频会话；
    2. 排除 LinDesk 进程自身的 PID；当检测到第三方媒体（网易云、QQ音乐、B站视频、游戏）正在发声时，壁纸视频音量以 300ms 缓动平滑淡出至 0；
    3. 第三方音频停止 2 秒后，壁纸音量无缝淡入恢复，彻底消除音频打架痛点。

7.2 壁纸组件的使用规范 (Usage Experience)

壁纸作为桌面沉浸感基座，在体验设计上严格保障视觉美感与免打扰人机工学：

  • 16:9 实时工坊画板 (StudioPreviewCanvas)：以 16:9 黄金比例等比还原现代高清/4K 屏幕视口，画布内运行真实的粒子仿真循环；
  • 桌面图标模拟浮层 (Desktop Icons Mock Overlay)：在画板上叠加半透明真实桌面图标排布网格与文本标签，直观验证动态背景在复杂光影下是否会导致桌面图标文字不可辨识；
  • 智能免打扰音频策略：
    • 动态静音仲裁：当检测到前台任何其他应用程序（如播放器、网页视频、游戏、会议软件）有音频输出时，壁纸自动瞬时静音；
    • 非桌面态绝对静音：离开桌面、最小化或处于锁屏状态时，绝对禁止发出声音；
    • 工坊全局音量控制：支持 0%~100% 无级调节音量与一键静音快捷开关；
  • 桌面鼠标交互协同（6px 曼哈顿位移仲裁）：
    • 纯视频/被动壁纸（interactive: false）：鼠标事件 100% 无损穿透给桌面图标层；
    • 粒子/互动壁纸（interactive: true）：鼠标微动（位移 < 6px）交付壁纸接收粒子引力扰动；一旦鼠标拖拽位移 ≥ 6px，宿主立即抢占并仲裁为原生桌面多选框选（SelectArea），彻底根除“选图标与玩壁纸冲突”的缺陷。

window.LinDesk.wallpaper.onPropertyChange(function (prop) {

});

7.4 壁纸组件的限制体系 (Hard Restrictions)

三重硬限制红线：为保障系统绝对稳定与游戏极致帧率，宿主对壁纸执行底层物理约束：
  • API 隔离红线：壁纸运行沙箱中严格禁用 LinDesk.widget 容器操作（如 close()、openSettings()），防止壁纸误调导致桌面背景异常黑屏；壁纸仅允许调用 LinDesk.system 查询硬件与 LinDesk.wallpaper 监听参数；
  • 渲染帧率强制锁 (60FPS / 30FPS)：宿主对 CEF OSR 离屏渲染强制执行 60FPS（或省电模式 30FPS）帧率锁，严禁 WebGL/Shader 无限制跑满 GPU 造成笔记本发热降频；
  • 全屏独占智能休眠 (0.0% CPU/GPU)：当前台启动独占全屏 3D 游戏（如 CS2、赛博朋克 2077）、全屏播放视频或 PPT 演示时，宿主检测后立即调用 WasHidden(true) 暂停渲染管线与媒体解码，使壁纸算力开销归零；退回桌面时瞬时唤醒恢复首帧呈现；
  • 文件与进程硬拦截：禁止任何 ../../ 目录穿越请求；openPath 物理阻断一切可执行二进制程序启动。

10. 风险与依赖

  • 数据隔离红线：组件系统任何流程禁止读写 data.dat|data.json 及伴生文件；拆 DLL 时 BoxManager / LayoutPersistenceService / DesktopItemLoader 留在主程序（见 2.1，列入验收）。
  • DLL 加载 / CEF 初始化失败：版本不匹配、杀软拦截、缺 VC 运行库——安装流程显式报错（原因 + 建议），不做静默失败。
  • 运行时更新中断：解压先落临时目录 + 原子 move，旧包 .old 备份，加载失败自动回滚。
  • 卸载数据语义：卸载组件系统不删组件包/组件数据/壁纸配置，重新安装自动恢复；确认弹窗写明该语义。
  • 开源组件安全性兜底：虽然开放普通 Web 运行，但通过 openPath 物理拦截二进制执行与目录穿越阻断，从操作系统物理层杜绝恶意提权与病毒运行风险。
  • 崩溃风暴熔断：若某组件实例反复崩溃（如 60s 内连续 3 次），宿主自动熔断停用该实例并向用户弹出排查建议，防止拖垮整个桌面宿主。
组件系统方案：以普通前端开发者友好为核心，实现纯 Web 极简架构与严格物理隔离。P0 核心地基（包与目录解耦、window.LinDesk 注入、创作者本地热重载）全面推进中。
