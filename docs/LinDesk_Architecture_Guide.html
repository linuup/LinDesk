LinDesk 架构指南

版本：当前版（WebView2 已彻底移除，CEF OSR + 独立组件运行时） 依据：src 源码只读盘点 更新：2026-10-14

1. 系统总体定位与技术栈

LinDesk 是一款面向 Windows 平台的桌面整理与小组件增强软件：在系统桌面上叠加一层自绘桌面（图标管理、收纳盒 LinBox），并以 HTML 组件系统（LinWidget）在桌面直接渲染信息小组件。组件系统以独立运行时形态随主程序分发，由 LinDesk 负责安装 / 卸载 / 动态加载。

层次技术 / 库职责
宿主核心C++ / Qt Widgets、CMake、vcpkg进程生命周期、桌面宿主嵌入（WorkerW）、事件调度、设置、更新、日志。
桌面交互Qt Widgets、GDI/D2D全屏自绘画布、图标网格布局、框选、右键菜单、LinBox 收纳盒。
组件渲染CEF（Chromium）离屏渲染 OSRLinWidget 组件像素帧离屏渲染，统一绘制管线合成到桌面。
组件运行时LinWidgetRuntime.dll（独立 DLL）组件系统独立运行库，由 RuntimeInstaller 安装、LinWidgetRuntimeBridge 动态加载。
组件生态HTML5 / CSS / JS（组件包）11 个内置组件（时钟、监控、天气、便签、待办、壁纸等）。
日志 / 崩溃spdlog + CrashHandler分级滚动日志（%LOCALAPPDATA%/LinDesk/logs/）、崩溃转储（crash/）。
更新 / 发布Qt Network（OpenSSL）+ Inno Setup + GitHub API版本检查、按位数下载安装包、x86/x64 双架构打包与发布。

历史说明：旧 WebView2（Edge）渲染栈已彻底移除（源码中无 LinWidgetWebViewRuntime / LinWallpaperWebViewRuntime / QAxWidget），仅 CEF 桥内保留 window.chrome.webview 兼容垫片，使旧组件代码无需修改即可运行。

2. 桌面底座与统一绘制架构

2.1 桌面挂载（WorkerW）

LinDesktop 通过 Win32 挂载到系统桌面：向 Progman 发送 0x052C 消息拆分 WorkerW，找到 SHELLDLL_DefView 下方的 WorkerW 句柄，SetParent(linDesktopHwnd, workerWHwnd) 嵌入，与系统桌面同生共灭。

2.2 三层统一绘制管线

桌面呈现采用单条 QPainter 绘制管线（不依赖原生子窗口 HWND 层级，避免遮挡与 UpdateLayeredWindowIndirect 报错）：

+-------------------------------------------------------+
|  1. 静态系统壁纸 / 壁纸组件帧（LinDesktop 背景绘制）    |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|  2. CEF OSR 小组件画布（LinWidgetCanvasWidget）         |
|     - renderCanvas(painter, dirtyRegion)              |
|     - 无组件时：default_page.html 毛玻璃引导卡片        |
|     - 有组件时：各组件 OSR 帧按图层合成                 |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|  3. 桌面图标与收纳盒（ListView / LinBox）               |
|     - 图标渲染数据缓存、框选、重命名、高亮              |
+-------------------------------------------------------+

ListView::paintEvent 按嵌入/浮动模式调整组件画布与图标层的先后：嵌入模式组件画布先画（组件在图标下方），浮动模式后画（组件在图标上方）。壁纸组件默认占满 ListView 背景，活动且非互动时置于最底层。

2.3 防抢占与自愈

  • 桌面宿主窗口监听（startDesktopHostWindowMonitor）：监测 EVENT_OBJECT_CREATE / DESTROY。
  • 层级脱落时触发恢复（scheduleLinWidgetLayerRecovery / syncLinWidgetLayer）。

3. LinWidget 组件系统（核心维护重点）

3.1 独立运行时与动态加载（主程序可脱离运行）

组件系统是独立于主程序的运行时 DLL（LinWidgetRuntime.dll），主程序默认不带组件功能也能独立运行；用户经 LinDesk 设置界面安装组件系统后启用。相关代码：src/desktop/runtime/RuntimeInstaller.*、src/desktop/widgets/runtime_export.*。

  • 安装：RuntimeInstaller::installRuntime 从随包 zip 解压安装到 %APPDATA%/LinDesk/runtime/linwidget/，记录 runtimeVersion。
  • 加载：LinWidgetRuntimeBridge 用 LoadLibraryW 动态加载 DLL，按函数指针表（linwidget_* 导出）解析接口；搜索顺序为 ① 程序目录 runtime/linwidget/LinWidgetRuntime.dll（开发热更新）→ ② 程序目录根 → ③ 用户数据目录已安装运行时。
  • 卸载：uninstallRuntime 先 unloadRuntime 释放 DLL，再递归删除运行时目录，保留用户组件（LinWidgets/）与组件数据（LinWidgetsData/），不会影响旧版本已使用的图标与 Box 数据。
  • 版本管理：Debug 模式拒绝加载 Release 版用户运行时（避免 Qt ABI 崩溃）；本地构建优先。

与主程序集成：主程序启动流程 main.cpp 在运行时可用时经 RuntimeInstaller::loadInstalledRuntime(ctx) 初始化；ListView 中组件画布、壁纸互动等能力均通过 LinWidgetRuntimeBridge 查询运行时是否加载。组件系统安装/卸载的入口见组件系统方案文档。

3.2 承载方式：每组件一个独立 CEF OSR 实例

每个运行的小组件拥有独立 CefOsrBrowserInstance（位于 src/desktop/widgets/cef/）：

  • 启动分流：WidgetManager::launchWidgetInstance 在运行时可用时 new CefOsrBrowserInstance(instanceId) → create(entryUrl, geometry)，存入 m_osrBrowsers。
  • 帧合成：frameReady(wid, geom, img, dirty) → LinWidgetCanvasWidget::updateWidgetFrame → ListView::paintEvent 的 renderCanvas。
  • 占位页：m_defaultOsrBrowser（__default_page__）加载 default_page.html，仅在无组件运行时显示。
  • 输入路由：鼠标 / 滚轮 / 键盘（sendKeyEvent → CefKeyEvent）按 widgetId 查 m_osrBrowsers 转发。
  • 本地资源：通过 CefResourceRequestHandler / 自定义 Scheme（linwidget://）由 C++ 直接读取本地组件包目录返回资源流，避免 file:// 跨域限制。

3.5 内置组件包（9 个）

位于 src/resources/LinWidgets/，遵循标准组件包规范（manifest.json + entry 页面）：Clock、SysMonitor、Weather、Notes、Timer、Todo、WaterTracker、Wallpaper。

  • 壁纸组件（Wallpaper）：特殊组件类型，可在组件内设置视频或图片，默认尺寸占满整个 ListView 背景；活动时经 hasActiveWallpaper / isWallpaperInteractive 控制互动层级，替代旧 WebView2 动态壁纸方案。
  • 尺寸与权限声明以各组件 manifest.json 为准。

4. 消息协议与桥接

4.1 消息协议（WidgetMessageTypes）

src/desktop/widgets/linwidget/WidgetMessageTypes.h 定义字符串枚举 + makeWidgetMessage(type, widgetId)：launch / ready / error、组件几何（add_widget / update_widget_geometry / widget_geometry_changed / move / resize / close）、系统信息（system_info_request/response/update）、存储（storage_request/response）、实例管理（create/list/close/remove_widget_instance_*）、设置（open_widget_settings / theme_changed）。待规范化：无 requestId / 超时 / 错误码。

4.2 传输层现状 已实现

  • CEF 消息桥：CefOsrBrowserInstance::injectBridgeScript 在页面加载完成时向主框架注入桥脚本；JS → C++ 经 onWebMessageReceived（页面 postMessage 转发）；C++ → JS 经 sendMessageToWeb（executeJavaScript 分发），WidgetManager 统一 handleRuntimeMessage 处理。
  • WebView2 兼容垫片：桥内保留 window.chrome.webview 兼容对象（postMessage / addEventListener / removeEventListener / __dispatch），旧组件（如 Notes）无需改写即可收发消息。

4.3 组件侧 API 目标形态（window.desktop）

组件加载后注入 window.desktop 桥对象：

  • 身份与就绪：instanceId / widgetId / widgetName、await window.desktop.ready。
  • 几何控制：resizeWidget / setWidgetGeometry / setResizeUiVisible / openSettings。
  • 存储：storage.instance.set/get/remove/clear/all、storage.widget.*（跨实例共享）。
  • 系统信息（需 desktop 权限）：systemInfo.getSnapshot()、systemInfo.watch(cb, interval)。
  • 实例管理：instances.create/list、instance.close/remove。

5. 数据持久化与存储拓扑

运行时配置分散在用户目录（AppPaths 定义）：

%APPDATA%/LinDesk/
  ├── config.ini                  # 应用设置（QSettings IniFormat）
  ├── data.dat                    # 桌面布局与 Box 数据（Release；Debug 用 data.json）
  ├── Menuexclusions.dat          # 右键菜单排除项（Debug 用 Menuexclusions.json）
  ├── LinWidgets/
  │     └── registry.json         # 组件注册表 + 布局配置
  ├── LinWidgetsData/             # 各组件数据仓储
  ├── LinWallpapers/
  │     └── registry.json         # 壁纸组件注册表
  ├── plugins/                    # 插件目录（*.dll 扫描）+ ocr_config.ini
  └── runtime/linwidget/          # 组件系统运行时（LinWidgetRuntime.dll，经 LinDesk 安装）
%LOCALAPPDATA%/LinDesk/
  └── logs/                       # spdlog 滚动日志
        └── crash/                # 崩溃转储
程序目录/
  ├── runtime/linwidget/          # 开发/随包运行时（优先加载，热更新）
  └── resources/wallpapers/       # 内置壁纸资源
  • 桌面与 Box 持久化：BoxManager 管理盒子集合，DesktopItemLoader 装载桌面项；图标缓存 IconCacheManager（LRU，上限 4096，支持按前缀失效）负责运行时缓存，不落盘。
  • 组件持久化：布局（位置/尺寸/zOrder/可见性）经 ConfigManager → registry.json，启动时 restoreFromConfig 恢复；组件数据仓储在 LinWidgetsData/。
  • 显示名覆盖：DesktopItemLoader::applyDisplayNameOverride 在 UI 层将特定路径（如 WPS 云盘）显示为自定义名称（中/英分语言），不改物理文件名。

6. 日志与崩溃处理

  • LogManager（src/services/LogManager.*）：基于 spdlog 双 logger 分流（主日志 desktop.log + 错误双写 desktop-error.log；组件系统独立日志 linwidget.log，按 [LinWidget] 消息前缀自动分流，均 20MB × 7 份滚动）+ 控制台/MSVC sink；main.cpp 启动时 LogManager::initialize()、退出时 shutdown()；日志落在 %LOCALAPPDATA%/LinDesk/logs/。
  • CrashHandler（src/services/CrashHandler.cpp）：崩溃时写转储到 logs/crash/，并在退出路径先关闭日志确保落盘。
  • 组件与 CEF 日志：组件运行时 Qt 日志（[LinWidget][...] 前缀）独立写入 linwidget.log；CEF 内部日志写 cef.log，初始化参数快照写 cef_init_trace.log（同目录管理，linWidgetLogsDir = 日志目录）。

7. 更新与发布（双架构）

  • 版本检查：UpdateChecker（src/services/update/）请求 GitHub API 元数据；按位数匹配资产：#ifdef _WIN64 → _x64.exe，否则 → _x86.exe（UpdateChecker.cpp:150-153）；x86 通道使用 update_x86.json。
  • 下载与安装：UpdateDownloader 下载对应架构安装包（文件名带架构后缀），SettingUI 展示进度并拉起安装。
  • 打包：installer/package.iss（Inno Setup）支持 MyArch / BuildDir / PackageOutputDir 命令行参数化，输出 LinDesk_Setup_<版本>_x64.exe / _x86.exe；x64 包声明 ArchitecturesAllowed=x64compatible。
  • 发布：scripts/publish_release.py 双架构配置（installer_suffix _x64/_x86、x86 额外写 update_x86.json），经 GitHub API 上传 Release 资产（PAT 注入，脚本已入 .gitignore）。
  • 构建：CMake 按 64/32 位选择 Qt（msvc2019_64 / msvc2019）与 CEF（3rdparty/cef / 3rdparty/cef32）。
