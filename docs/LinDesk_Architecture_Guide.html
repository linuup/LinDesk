LinDesk 架构指南

版本：当前版（WebView2 已彻底移除，CEF OSR + 独立组件运行时） 依据：src 源码只读盘点 更新：2026-11-02（同步纯 Web 极简架构与六大核心管道）

1. 系统总体定位与技术栈

LinDesk 是一款面向 Windows 平台的桌面整理与小组件增强软件：在系统桌面上叠加一层自绘桌面（图标管理、收纳盒 LinBox），并以 HTML 组件系统（LinWidget）在桌面直接渲染信息小组件。组件系统以独立运行时形态随主程序分发，由 LinDesk 负责安装 / 卸载 / 动态加载。

层次技术 / 库职责
宿主核心C++ / Qt Widgets、CMake、vcpkg进程生命周期、桌面宿主嵌入（WorkerW）、事件调度、设置、更新、日志。
桌面交互Qt Widgets、GDI/D2D全屏自绘画布、图标网格布局、框选、右键菜单、LinBox 收纳盒。
组件渲染CEF（Chromium）离屏渲染 OSRLinWidget 组件像素帧离屏渲染，统一绘制管线合成到桌面。
组件运行时LinWidgetRuntime.dll（独立 DLL）组件系统独立运行库，由 RuntimeInstaller 安装、LinWidgetRuntimeBridge 动态加载。
组件生态HTML5 / CSS / JS（组件包）11 个内置组件（时钟、监控、天气、便签、待办、壁纸等）。
日志 / 崩溃spdlog + CrashHandler分级滚动日志（%LOCALAPPDATA%/LinDesk/logs/）、崩溃转储（crash/）。
更新 / 发布Qt Network（OpenSSL）+ Inno Setup + GitHub API版本检查、按位数下载安装包、x86/x64 双架构打包与发布。

历史说明：旧 WebView2（Edge）渲染栈已彻底移除（源码中无 LinWidgetWebViewRuntime / LinWallpaperWebViewRuntime / QAxWidget），仅 CEF 桥内保留 window.chrome.webview 兼容垫片，使旧组件代码无需修改即可运行。

2. 桌面底座与统一绘制架构

2.1 桌面挂载（WorkerW）

LinDesktop 通过 Win32 挂载到系统桌面：向 Progman 发送 0x052C 消息拆分 WorkerW，找到 SHELLDLL_DefView 下方的 WorkerW 句柄，SetParent(linDesktopHwnd, workerWHwnd) 嵌入，与系统桌面同生共灭。

2.2 三层统一绘制管线

桌面呈现采用单条 QPainter 绘制管线（不依赖原生子窗口 HWND 层级，避免遮挡与 UpdateLayeredWindowIndirect 报错）：

+-------------------------------------------------------+
|  1. 静态系统壁纸 / 壁纸组件帧（LinDesktop 背景绘制）    |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|  2. CEF OSR 小组件画布（LinWidgetCanvasWidget）         |
|     - renderCanvas(painter, dirtyRegion)              |
|     - 无组件时：default_page.html 毛玻璃引导卡片        |
|     - 有组件时：各组件 OSR 帧按图层合成                 |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|  3. 桌面图标与收纳盒（ListView / LinBox）               |
|     - 图标渲染数据缓存、框选、重命名、高亮              |
+-------------------------------------------------------+

ListView::paintEvent 按嵌入/浮动模式调整组件画布与图标层的先后：嵌入模式组件画布先画（组件在图标下方），浮动模式后画（组件在图标上方）。壁纸组件默认占满 ListView 背景，活动且非互动时置于最底层。

2.3 防抢占与自愈

  • 桌面宿主窗口监听（startDesktopHostWindowMonitor）：监测 EVENT_OBJECT_CREATE / DESTROY。
  • 层级脱落时触发恢复（scheduleLinWidgetLayerRecovery / syncLinWidgetLayer）。

2.4 桌面核心人机工学交互与动效架构

  • LinBox 缓动折叠与自动悬停展开 (Roll-up / Auto-Peek)： 折叠与展开驱动采用 QPropertyAnimation（200ms OutCubic 缓动曲线），冷启动状态瞬切无跳闪； 在折叠状态下，鼠标光标悬停标题栏达 150ms 后盒子自动下卷展开，移出盒子区域 300ms 延时收起； 内置防溢出边界防护（碰撞底部任务栏时自动上翻），设置中心提供 AutoPeekOnHover 与 AutoPeekInstant 独立开关控制。
  • 标题栏双击分区命中模型 (Hit-Testing Partition)： 按命中优先级分四区：① 折叠与视图切换按钮直接触发原生动作；② 映射图标区双击在资源管理器中打开目标物理文件夹；③ 标题文本热区（mappedTitleHitRect，依据实际绘制文本宽度与内边距紧凑计算）双击进入重命名；④ 其余空白区双击执行 toggleCollapse() 折叠/展开，彻底消除双击误触发重命名的冲突。
  • 12px 屏幕边缘与相邻盒子磁吸 (Magnetic Snapping)： 考虑 8px 隐形拉伸手柄准确换算实际视觉几何，当拖拽盒子边缘接近屏幕工作区或其它盒子小于 12px 时产生微阻尼并自动对齐坐标，实现相邻盒子 0px 缝隙完美贴合；支持按住 Alt 键实时脱离吸附自由微调。
  • 盲打跳选定位 (Type-to-Select) 与 Shell 撤销桥接 (Ctrl + Z)： 在 ListView::keyPressEvent 中维护 800ms 按键缓冲区与防抖计时器，支持全字符串与 GBK 拼音首字母检索，连续敲击同字符在匹配项间轮询切换，支持激活 Box 内部跳选与居中平滑滚动；拦截 Ctrl + Z 发送 FCIDM_SHVIEW_UNDO (28699) 消息无缝桥接 Windows Explorer Shell 原生撤销栈。
  • 双击空白隐藏桌面淡入淡出过渡管线： 引入 220ms InOutQuad 透明度过渡动画，驱动 m_desktopHideOpacity 变量，全屏普通图标与 Box 容器同频渐隐；隐藏态自动阻断鼠标命中防误触；设置中心与桌面右键菜单提供 DoubleClickHideIcons 与 FadeTransitionOnHide 独立且双向同步绑定的配置项。

2.5 三层桌面交互架构与冲突仲裁体系 (Three-Tier Interaction Architecture)

在 LinDesk 桌面环境下，存在三种不同层级、不同特性的可视与交互主体：原生桌面图标/收纳盒、局部小组件 (LinWidgets) 与 全屏动态交互壁纸 (Live Wallpaper)。系统建立严格的五层 Z-Order 模型与冲突仲裁状态机：

  • 严格的分层 Z-Order 模型： Layer 0（浮层右键菜单/模态弹窗，绝对优先）→ Layer 1（LinBox 桌面收纳盒）→ Layer 2（桌面图标与快捷方式）→ Layer 3（LinWidgets 桌面小组件，局部矩形/透明感知）→ Layer 4（动态交互壁纸，全屏覆盖底层）。
  • 命中判定解耦 (Decoupled Hit-Testing)： WidgetManager::widgetAt 与 LinWidgetRuntimeBridge::widgetAt 严格排除壁纸，只返回真正的局部小组件；全屏动态壁纸由专属的壁纸管道独立承载，杜绝桌面空白区域被误判为组件而截断事件。
  • MouseMove 非互斥 60fps 广播管道： 鼠标在桌面上移动时，采用非互斥广播（Parallel Routing）模式：一方面正常维护桌面图标 Hover 态与小组件悬停，另一方面以 60fps（16ms 节流）向动态壁纸派发鼠标坐标，让黑洞引力场、星空粒子与水波跟随丝滑流动，两者完全兼得。
  • 6px 曼哈顿位移阈值仲裁状态机 (Drag-Threshold Arbitration)： 鼠标在空白区域按下时，记录起始点 m_pendingWallpaperClick = true 暂缓决策；当鼠标拖拽位移超过 QApplication::startDragDistance()（通常 6px）时，立即识别为用户意图是桌面多选框选，唤起 SelectArea 蓝色选框并向壁纸补发释放；若原地释放（位移未超阈值），则识别为壁纸点击并清理桌面选中态。
  • 键盘焦点与全局快捷键安全隔离： 当小组件获得输入焦点时，全局文件破坏性操作（如 Delete 键删除文件、F2 重命名）被严格限制在小组件文本域内，绝不误删桌面选中的文件图标；点击桌面空白处立即调用 clearWidgetFocus() 取回桌面焦点。

2.6 高分屏 High-DPI 缩放适配与防模糊

  • 全链路缩放计算体系：全局网格尺寸、图标间距、选中外边框、内边距全量收口于 scaledPx() 缩放计算，严格杜绝硬编码像素；无论 100%、125%、150%、175% 还是 200% 缩放比率，桌面布局与元素均精准按比例呈现。
  • 文字渲染高精光栅化 (TextRenderCache)：桌面图标文本标签在 TextRenderCache 缓存绘制时，不仅记录文本与配色哈希，更将 devicePixelRatio 纳入缓存 Key，并在高分屏下按物理像素尺寸生成 QPixmap，彻底消除 125%/150% 缩放下字体发虚、边缘毛刺问题。
  • 壁纸物理分辨率同步解码：壁纸在桌面底座 LinDesktop 解码时，按 screenSize * devicePixelRatio 缩放至屏幕物理像素，再以高画质双三次插值渲染，消除 4K 高分屏壁纸拉伸模糊。
  • 毛玻璃滤镜与菜单精简：LinBox Win11 亚克力与毛玻璃模糊半径自适应 DPI 缩放，避免高缩放下模糊衰减；右键菜单去除冗余的“收起盒子”条目，统一由右上角折叠按钮与双击空白承载。

3. LinWidget 组件系统（核心维护重点）

3.1 独立运行时与动态加载（主程序可脱离运行）

组件系统是独立于主程序的运行时 DLL（LinWidgetRuntime.dll），主程序默认不带组件功能也能独立运行；用户经 LinDesk 设置界面安装组件系统后启用。相关代码：src/desktop/runtime/RuntimeInstaller.*、src/desktop/widgets/runtime_export.*。

  • 安装：RuntimeInstaller::installRuntime 从随包 zip 解压安装到 %APPDATA%/LinDesk/runtime/linwidget/，记录 runtimeVersion。
  • 加载：LinWidgetRuntimeBridge 用 LoadLibraryW 动态加载 DLL，按函数指针表（linwidget_* 导出）解析接口；搜索顺序为 ① 程序目录 runtime/linwidget/LinWidgetRuntime.dll（开发热更新）→ ② 程序目录根 → ③ 用户数据目录已安装运行时。
  • 卸载：uninstallRuntime 先 unloadRuntime 释放 DLL，再递归删除运行时目录，保留用户组件（LinWidgets/）与组件数据（LinWidgetsData/），不会影响旧版本已使用的图标与 Box 数据。
  • 版本管理：Debug 模式拒绝加载 Release 版用户运行时（避免 Qt ABI 崩溃）；本地构建优先。

与主程序集成：主程序启动流程 main.cpp 在运行时可用时经 RuntimeInstaller::loadInstalledRuntime(ctx) 初始化；ListView 中组件画布、壁纸互动等能力均通过 LinWidgetRuntimeBridge 查询运行时是否加载。组件系统安装/卸载的入口见组件系统方案文档。

3.2 承载方式：每组件一个独立 CEF OSR 实例

每个运行的小组件拥有独立 CefOsrBrowserInstance（位于 src/desktop/widgets/cef/）：

  • 启动分流：WidgetManager::launchWidgetInstance 在运行时可用时 new CefOsrBrowserInstance(instanceId) → create(entryUrl, geometry)，存入 m_osrBrowsers。
  • 帧合成：frameReady(wid, geom, img, dirty) → LinWidgetCanvasWidget::updateWidgetFrame → ListView::paintEvent 的 renderCanvas。
  • 占位页：m_defaultOsrBrowser（__default_page__）加载 default_page.html，仅在无组件运行时显示。
  • 输入路由：鼠标 / 滚轮 / 键盘（sendKeyEvent → CefKeyEvent）按 widgetId 查 m_osrBrowsers 转发。
  • 本地资源：通过 CefResourceRequestHandler / 自定义 Scheme（linwidget://）由 C++ 直接读取本地组件包目录返回资源流，避免 file:// 跨域限制。

3.5 小组件尺寸调整与交互控制体系 (基于 Ctrl 快捷键的全能交互)

LinWidget 小组件是富 Web 容器（可能包含靠边的表单、滑块、滚动条与按钮）。为避免无条件拦截边缘破坏 Web 自身功能，系统确立以 Ctrl 键作为桌面宿主编排修饰符的设计规范：

  • 按住 Ctrl + 边缘 10px 智能缩放：光标悬停小组件四周边缘并按住 Ctrl 时，自动切换为双向缩放光标（SizeHorCursor、SizeVerCursor、SizeFDiagCursor、SizeBDiagCursor），按住左键拖拽实时自适应拉伸并受 Manifest 最小/最大尺寸保护。
  • 按住 Ctrl + 内部拖拽自由移动：鼠标在小组件内部按住 Ctrl 时光标切换为 SizeAllCursor，左键拖拽可任意平移组件至屏幕其他位置，松开即刻落盘持久化。
  • 按住 Ctrl + 鼠标滚轮等比平滑缩放：鼠标悬停在组件上方并按住 Ctrl 滚动滚轮，以鼠标悬停点为锚点进行 ±8% 步进的等比例无级平滑缩放，拦截事件避免穿透导致网页内部滚动。
  • Fluent 强调色视觉辅助反馈：按住 Ctrl 悬停或调整时，宿主外层实时绘制 2px Fluent Accent 高亮描边、8 个控制点调节手柄与顶部实时尺寸胶囊徽章（如 360 × 200），松开即自然淡出。
  • 右键快捷尺寸规格菜单：在小组件上右键单击弹出专属上下文菜单，提供标准网格尺寸一键切换（小卡片 200×200、标准条状 360×200、大卡片 400×300、全宽展板 540×320），并可直接执行重新加载、打开小组件设置与移除小组件。

3.6 组件与壁纸包规范（解耦分流）

遵循标准 .lw 归档包规范（manifest.json + index.html），按 type 严格物理解耦：

  • 桌面小组件 (LinWidgets/)：type: "widget"，包含 Clock、SysMonitor、Weather、Notes、Timer、Todo、WaterTracker 等。在桌面组件层浮动/嵌入渲染，支持 Ctrl 8 方向缩放、自由平移与网格预设。
  • 动态壁纸 (Wallpapers/)：type: "wallpaper"，独立存放于壁纸库；采用 wallpaperType（"web" | "video" | "picture"）与 interactive（true | false）正交模型；全屏置底 OSR 渲染，接入 6px 曼哈顿位移仲裁与前台发声智能静音。

3.7 组件系统全流程闭环拓扑与六大核心管道

LinDesk 组件系统打通了从底层二进制装载、磁盘包分流、多层像素混流到原生能力注入与全屏休眠的完整闭环，由六大管道协同运行：

核心管道系统职责与内部机制用户体验与交付价值
1. 运行时装载流
(Runtime Lifecycle)		 主程序与 CEF 零静态依赖；LinWidgetRuntime.dll 按需 LoadLibrary；支持在线下载进度条、离线 zip 安装、SHA-256 校验与无重启动态卸载。 未安装时 0 额外进程、0 显存占用，底座纯绿色秒开；随时安全启停与更新。
2. 包管理与分流流
(Package & Routing)		 统一 .lw 格式；安装器按 type 自动分流解压至 LinWidgets/（组件）与 Wallpapers/（壁纸）；开发期支持明文文件夹直接放入热读取。 壁纸与组件物理级彻底解耦，彻底消灭历史混放与目录混乱。
3. 四层图层混合流
(Compositing & Layers)		 单条 QPainter 绘制管线无窗口句柄叠加：Layer 0（系统底层）→ Layer 1（壁纸层，CEF OSR 全屏）→ Layer 2（桌面图标与 LinBox 容器）→ Layer 3（桌面小组件）→ Layer 4（交互框选与 Ctrl 手柄）。 杜绝 Windows DWM 子窗口闪烁与白屏，像素级支持 Alpha 透明通道与亚克力混流。
4. 交互穿透与仲裁流
(Input Arbitration)		 小组件遵循「Ctrl 键宿主编排（8 方向缩放/平移/滚轮等比缩放）」与「免 Ctrl 原生交付（透明区域穿透，不透明区域点击）」；全屏壁纸与图标框选执行「6px 曼哈顿位移仲裁」。 壁纸粒子互动丝滑，桌面拉框选图标零冲突，组件内部网页按钮/输入框 100% 原生响应。
5. 原生注入与数据流
(window.LinDesk)		 每个组件与壁纸以 linwidget:/// 独占 Origin，天然获得 Chromium 隔离的 localStorage/IndexedDB；宿主仅注入 window.LinDesk（system 硬件监控、shell 资源管理器安全定位、widget 容器控制、wallpaper 参数同步）。 普通能力直接使用原生 Web 标准；数据永不污染 LinDesk 宿主；杜绝恶意二进制拉起。
6. 能耗治理与熔断流
(Suspension & Fault)		 前台独占运行 3D 游戏（如 CS2、赛博朋克 2077）或视频放映时，宿主检测后立即调用 WasHidden(true) 挂起渲染管线与媒体解码（CPU/GPU 0.0%）；前台发声自动静音；单组件 60s 内累计崩溃 3 次触发熔断保护。 绝对不抢占前台生产力与游戏算力；避免宿主陷入死循环崩溃风暴。

4. 原生能力注入与 window.LinDesk 规范

4.1 原生能力注入架构 (window.LinDesk)

宿主彻底摒弃复杂的专有存储与网络 IPC 包装，普通能力 100% 原生交付浏览器标准（localStorage、fetch、Canvas/WebGL），仅在全局注入 window.LinDesk 提供四项底层原生补足能力：

  • LinDesk.system：硬件监控指标快照（getMetrics()）与 1s 周期订阅（onMetrics(cb)）。
  • LinDesk.shell：资源管理器目录浏览与文件定位（openPath(path)，物理拦截可执行二进制）、安全默认浏览器外链（openUrl(url)，限 http/https）。
  • LinDesk.widget：容器关闭当前组件（close()）与呼出组件管理设置（openSettings()）（壁纸沙箱禁用）。
  • LinDesk.wallpaper：工坊滑块/颜色/开关实时变动监听（onPropertyChange(cb)）（仅壁纸生效）。

4.2 Chromium 域隔离持久化

每个小组件与壁纸以 linwidget:/// 作为独立 Origin，天然享有 Chromium 内核分配的独立 localStorage / IndexedDB 存储沙箱，零私有代码实现物理隔离，永不污染 LinDesk 宿主数据。
