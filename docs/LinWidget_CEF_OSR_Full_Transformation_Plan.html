LinWidget CEF 离屏渲染 (OSR) 全链路改造方案

彻底解耦 Win32 HWND 层级限制，将 HTML5 桌面组件以透明 BGRA32 内存帧形式直接合成至 ListView 图标下方的生产级改造设计白皮书。

1. 核心架构决议汇总 (/grill-me)

通过深入的需求与技术决策走查，全链路改造方案的关键技术路径已全面敲定：

决策分支 最终决议 核心设计理由与技术收益
核心渲染方案 全面转向 CEF 离屏渲染 (OSR) 彻底摆脱 Win32 HWND 兄弟窗口剪裁、DWM 透明混合失真与 SetWindowRgn 锯齿，将网页渲染为内存像素帧由 Qt 自由合成。
图层组织与合成管线 独立底层透明画布控件 (LinWidgetCanvasWidget) 作为独立透明 QWidget 紧贴在 ListView 正下方；组件 60fps 脏矩形高频重绘完全隔离在画布层，零干扰 ListView 桌面图标绘制性能。
鼠标键盘交互分发 ListView 智能命中检测 + 精确事件注入 ListView 优先处理桌面图标（拖拽、打开）；点击空白区若落在组件区域，换算相对坐标后直接调用 CEF SendMouseClickEvent，纯 Qt 内存级判定无闪烁穿孔。
进程模型与消息调度 单主线程协同循环 + 独立子进程 主程序作为 Browser 进程，通过 QTimer (10ms) 触发 CefDoMessageLoopWork()；Renderer/GPU/Utility 托管于独立 LinDeskSubprocess.exe，杜绝死锁与崩溃扩散。
组件实例管理模型 多 CefBrowser 独立实例 每个桌面小组件运行在独立的 CefBrowser 实例中，JS 上下文、存储与异常完全隔离；由 LinWidgetCanvasWidget 统一按各组件桌面坐标进行拼版与渲染。
依赖接入与构建 辅助脚本一键拉取 + CMake 自动探测 提供 scripts/download_cef.ps1 按需下载预编译包，CMake 探测 3rdparty/cef 或 CEF_ROOT 自动使能，未就绪时优雅降级并输出配置指引。
落地实施节奏 全链路直接重构 (Direct Full-Pipeline) 直接调整 LinDesktop、WidgetManager 与 ListView 主链路，一次性完成桌面架构的彻底升级与联调。

2. 桌面分层与合成拓扑

架构核心收益：单一 Win32 根窗口，消灭所有 HWND 层级博弈

在此方案下，LinDesktop 是唯一的顶层嵌入式 Win32 HWND。底下的壁纸、组件画布、图标列表均为纯 Qt 窗口部件，Windows DWM 仅需管理单个桌面容器窗口，彻底避免任何 Win32 跨窗口黑边、穿孔或遮挡异常。

2.1 单根窗口三层架构

+--------------------------------------------------------------------------+
|  LinDesktop (顶层宿主 HWND，通过 embedToDesktop() 嵌入 Progman/WorkerW)     |
|                                                                          |
|  [ 底层 Layer 0: 壁纸绘制层 ]                                              |
|  - LinDesktop::paintEvent()                                              |

3. CEF OSR 运行时设计

3.1 独立子进程 (Subprocess) 设计

为满足工业级稳定性与 Chromium 沙盒规范，创建独立子进程二进制 LinDeskSubprocess.exe：

// src/desktop/widgets/cef/subprocess/main.cpp
#include <include/cef_app.h>
#include <windows.h>

int APIENTRY wWinMain(HINSTANCE hInstance, HINSTANCE, LPWSTR, int) {
    CefMainArgs main_args(hInstance);
    return CefExecuteProcess(main_args, nullptr, nullptr);
}

主程序 LinDesk.exe 在 CefSettings 中将 browser_subprocess_path 指向 LinDeskSubprocess.exe，确保渲染与 GPU 崩溃绝不波及桌面宿主。

3.2 单主线程协同消息泵 (Cooperative Pump)

主进程将 settings.multi_threaded_message_loop = false。在 CefManager 单例中配置一个高精度 QTimer (10ms)：

void CefManager::initMessageLoop() {
    m_cefLoopTimer = new QTimer(this);
    m_cefLoopTimer->setInterval(10); // 100Hz 消息分发轮询
    connect(m_cefLoopTimer, &QTimer::timeout, this, []() {
        CefDoMessageLoopWork();
    });
    m_cefLoopTimer->start();
}

3.3 多 CefBrowser 隔离实例与 OnPaint 管线

每个桌面组件对应一个 CefOsrBrowserInstance。在 CefRenderHandler 回调中接收 BGRA32 缓冲：

void CefOsrRenderHandler::OnPaint(CefRefPtr<CefBrowser> browser,
                                  PaintElementType type,
                                  const RectList& dirtyRects,
                                  const void* buffer,
                                  int width,
                                  int height) {
    if (type != PET_VIEW || !buffer || width <= 0 || height <= 0) {
        return;
    }

    // 内存数据封装为 QImage (Format_ARGB32_Premultiplied)
    QImage frame(static_cast<const uchar*>(buffer), width, height, width * 4, QImage::Format_ARGB32_Premultiplied);
    QImage clonedFrame = frame.copy(); // 独立深拷贝供 Qt 主线程合成

    QVector<QRect> qtDirtyRects;
    for (const auto& r : dirtyRects) {
        qtDirtyRects.append(QRect(r.x, r.y, r.width, r.height));
    }

    emit frameReady(m_widgetId, clonedFrame, qtDirtyRects);
}

4.2 坐标换算与 CEF 事件注入

bool ListView::handleWidgetInputForwarding(QMouseEvent* event, CefEventFlags modifiers) {
    const QPoint globalPos = event->pos();
    LinWidgetInstance* targetWidget = WidgetManager::instance()->findWidgetAt(globalPos);
    if (!targetWidget || !targetWidget->browserHost()) {
        return false;
    }

    // 转换为组件内部的局部坐标 (Local Coordinates)
    const QPoint localPos = globalPos - targetWidget->geometry().topLeft();

    CefMouseEvent mouseEvent;
    mouseEvent.x = localPos.x();
    mouseEvent.y = localPos.y();
    mouseEvent.modifiers = modifiers;

    cef_mouse_button_type_t btnType = MBT_LEFT;
    if (event->button() == Qt::RightButton) btnType = MBT_RIGHT;
    else if (event->button() == Qt::MiddleButton) btnType = MBT_MIDDLE;

    const bool mouseUp = (event->type() == QEvent::MouseButtonRelease);
    const int clickCount = (event->type() == QEvent::MouseButtonDblClick) ? 2 : 1;

    targetWidget->browserHost()->SendMouseClickEvent(mouseEvent, btnType, mouseUp, clickCount);
    return true;
}

5.2 CMakeLists.txt 配置规则

# 检测 CEF SDK
set(CEF_ROOT "${CMAKE_CURRENT_SOURCE_DIR}/3rdparty/cef" CACHE PATH "Path to CEF root")
if(EXISTS "${CEF_ROOT}/include/cef_app.h")
    message(STATUS "[CEF] Found CEF SDK at: ${CEF_ROOT}")
    set(LINDESK_HAS_CEF ON)
    add_definitions(-DLINDESK_HAS_CEF=1)
    include_directories(${CEF_ROOT})
    link_directories(${CEF_ROOT}/Release ${CEF_ROOT}/libcef_dll_wrapper/Release)

    # 独立子进程目标
    add_executable(LinDeskSubprocess WIN32 src/desktop/widgets/cef/subprocess/main.cpp)
    target_link_libraries(LinDeskSubprocess libcef libcef_dll_wrapper)

    # 主程序链接
    target_link_libraries(LinDesk PRIVATE libcef libcef_dll_wrapper)
else()
    message(WARNING "[CEF] CEF SDK not found in 3rdparty/cef. Run scripts/download_cef.ps1 to enable.")
    set(LINDESK_HAS_CEF OFF)
endif()

6. 全链路直接重构实施路径 (Implementation Roadmap)

1 依赖拉取脚本与 CMake 拓扑配置

创建 scripts/download_cef.ps1，在 CMakeLists.txt 中配置 LINDESK_HAS_CEF 自动探测逻辑，配置头文件与链接库路径，并定义 LinDeskSubprocess 目标。

2 CEF OSR 运行时核心封装 (CefManager / CefOsrBrowserInstance)

在 src/desktop/widgets/cef/ 下实现 CefManager 单例、CefOsrRenderHandler、CefOsrClient 与 CefOsrBrowserInstance，实现 OnPaint 向 Qt QImage 的安全深拷贝转发与 QTimer 消息泵驱动。

3 透明底层画布控件实现 (LinWidgetCanvasWidget)

实现纯透明 QWidget LinWidgetCanvasWidget，维护各组件画面的缓冲字典与脏矩形管理，在 paintEvent() 中利用 QPainter 进行高性能无缝 Alpha 混合绘制。

4 LinDesktop 视口层级挂载与 ListView 命中检测改造

在 LinDesktop 构造中实例化 LinWidgetCanvasWidget 并放置于 listView 正下方 (stackUnder(listView))；在 ListView.cpp 中接入 findDesktopStateAt 与 WidgetManager::findWidgetAt 判定，将未命中图标但落在组件交互区的鼠标事件换算并注入 CEF。

5 WidgetManager 全链路切换与端到端联调

将 WidgetManager 中小组件的创建与生命周期管理切至 CefOsrBrowserInstance，移除旧有的 Win32 HWND 兄弟窗口规避逻辑，在真实桌面上验证小组件在桌面图标下方的流畅 60fps 运行、透明混合与鼠标交互响应。
