LinDesk 产品介绍

定位：Windows 桌面增强工具 更新：2026-10-14 依据：当前代码（src 只读盘点）

1. 产品定位

LinDesk 是一个运行在 Windows 桌面上的增强层工具：在不替换系统桌面的前提下，为桌面提供更现代的图标管理、可定制的收纳容器（LinBox）和基于 HTML 的桌面小组件（LinWidget）体系。组件系统以独立运行时形态交付，主程序可脱离组件功能独立运行，用户按需经 LinDesk 安装/启用。

  • 桌面图标：网格对齐 / 自由摆放、自动排列、自然排序（数字与中文拼音）、多档视图、DPI 自适应。
  • 收纳盒：把桌面文件收纳进可自定义的卡片容器；可映射真实文件夹，文件变化实时同步。
  • HTML 小组件：时钟、便签、待办、系统监控、壁纸等组件直接渲染在桌面上，可置于图标层下方或上方。

2. 核心功能

2.1 桌面图标管理

  • 布局：网格对齐与自由位置两种模式，自动排列（按分类稳定排序）；视图切换时位置按比例重映射。
  • 排序：自然排序（file1, file2, file10）、按名称/大小/类型/修改时间、分类排序（系统、文件夹、应用、文档）；文件夹优先、隐藏/系统文件置后。
  • 视图：6 档图标尺寸（小/中/大/超大等），间隔可调，DPI 变化自动重排。
  • 系统图标：我的电脑、回收站等特殊图标可显示/隐藏管理（注册表监听自动刷新）。
  • 交互：框选、Ctrl/Shift 多选、重命名、剪切/复制/粘贴、拖放（含外部文件拖入建快捷方式）、双击隐藏图标、右键系统菜单扩展。
  • 图标获取：快捷方式/应用/文件夹分级提取（Shell API + 256 高清缩略图）；微软商店应用（UWP/MSIX）图标兼容；图标缓存 LRU 上限管理，文件变化按前缀失效。
  • 显示名覆盖：WPS 云盘等特定目录在 UI 显示为自定义名称（中/英分语言），不改物理文件名。

2.2 收纳盒（LinBox）

  • 自建容器：自定义标题、颜色、透明度、毛玻璃效果、折叠。
  • 映射文件夹：把任意本地文件夹"装进"桌面盒子，目录变化（增删改）实时同步。
  • 拖放收纳：桌面图标拖入盒子；盒子内项目支持打开、重命名、删除、多选拖拽。
  • 布局持久化：盒子位置、大小、成员列表保存并恢复（data.dat，Debug 用 data.json）。

2.3 HTML 组件系统（LinWidget）

  • 独立运行时：组件系统为 LinWidgetRuntime.dll，经 LinDesk 设置界面安装 / 卸载 / 启用；卸载时保留用户组件与数据；主程序无组件系统也能独立运行。
  • 组件包模型：每个组件是一个独立包（manifest.json + index.html + JS/CSS），可安装、卸载、启用/禁用。
  • 渲染：CEF OSR 离屏渲染，像素帧经统一绘制管线合成到桌面（组件层可置于图标下方或上方）；鼠标/滚轮/键盘输入按组件路由。
  • 内置组件（11 个）：时钟、计时器、便签、待办、系统监控、天气、新闻订阅、水杯提醒、API 测试器等，含壁纸组件（可设置视频或图片，默认占满 ListView 背景）。
  • 旧组件兼容：桥内保留 window.chrome.webview 兼容对象，WebView2 时代组件代码无需改写。
  • 权限：网络 / 存储 / 桌面 API 三级权限声明与校验。
  • 开发模式：监听组件目录变化热重载；开发项目可一键安装。
  • 持久化：组件布局（位置/大小/层级）保存到 registry.json，重启恢复。

2.4 系统集成与更新维护

  • 桌面文件实时监控：外部新建/删除/重命名文件即时反映到桌面（基于 Windows Shell 通知 + 目录监控）。
  • 系统右键菜单：集成原生资源管理器菜单（打开、属性、删除等），支持排除项管理。
  • 自动更新：GitHub Release 通道，按系统位数（x86/x64）自动匹配安装包下载安装；双架构安装包均发布。
  • 日志与崩溃：spdlog 分级滚动日志 + 崩溃转储（logs/crash/），便于问题定位。
  • 设置界面与调试面板：图标规则、组件管理与运行时安装、更新检查、渲染调试。

4. 架构概览

桌面渲染采用单条 QPainter 绘制管线（避免原生子窗口的 HWND 层级遮挡问题）：

  • 底层：系统静态壁纸 / 壁纸组件帧（视频或图片，默认 ListView 背景大小）。
  • 中层：CEF OSR 组件画布（每个组件独立 OSR 实例，帧按图层合成）。
  • 上层：桌面图标与收纳盒（ListView / LinBox）。

组件系统与主程序通过独立运行时 DLL + 导出函数桥集成（主程序可脱离运行）；组件与运行时的通信走统一消息协议（设置变更、系统信息、存储、实例管理）；布局/权限/注册表等逻辑为纯 C++ 层，与渲染引擎无关。架构细节见 架构指南，文档体系见 文档中心。

当前状态：WebView2 已彻底移除（旧组件经 chrome.webview 兼容桥运行）；CEF OSR 渲染、消息桥、输入路由、组件系统独立运行时安装/卸载、壁纸组件、日志与崩溃、双架构发布均已落地。组件权限沙箱、console 日志捕获、崩溃自动恢复、组件市场等见组件系统方案。
