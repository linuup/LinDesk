2. 已完成里程碑成果 (Milestones Achieved)

  • 冷启动零闪烁与首帧同频呈现：壁纸冷启动采用 loadBackImageSync() 同步解码就绪；彻底移除了启动时隐藏图标 80ms 的 onMenuRefresh()；首帧同屏呈现壁纸、桌面图标与所有 Box 已完成
  • 单例与递归防护：ListView 构造函数第一时间绑定 m_instance = this，根除构造期实例化子组件导致的死循环递归 已完成
  • 双架构构建支持与自动化部署：Debug 与 Release 全自动化编译验证，OpenSSL/CEF/资源文件自动化拷贝 已完成

2.2 现代上下文菜单 (Win11 Context Menu)

  • 独立宿主进程隔离：采用 Win11MenuIsland.exe 托管 WinUI 3 / XAML 现代菜单，避免主进程 COM 冲突与崩溃传染 已完成
  • 预热加速与缓存机制：右键链路深度优化，提供快速响应通道与超时兜底 已完成
  • 快捷操作与菜单合并：合并 Windows 系统原生菜单与 LinDesk 自定义操作，支持 View/Sort by/Paste/New Box 深度集成 已完成

2.3 小组件系统 (LinWidget) 基础设施

  • 单进程动态加载 CEF OSR 架构：主程序与 CEF 彻底解耦，按需加载 LinWidgetRuntime.dll，保持桌面底座轻量 已完成
  • 统一图层混流：小组件渲染在桌面图标下方、壁纸上方，根除 UpdateLayeredWindowIndirect 错误 已完成
  • 双向 IPC 消息信封与 API：系统信息快照与周期推送 (SystemInfo)、隔离持久化存储 (Storage)、动态壁纸 (Wallpaper) API 已完成
  • 三层桌面交互协同与冲突仲裁：widgetAt 排除全屏动态壁纸；MouseMove 60fps 广播管道；6px 曼哈顿位移仲裁全屏壁纸点击与桌面图标蓝色框选；键盘快捷键焦点隔离 已完成
  • 小组件尺寸全能调整体系 (Ctrl 组合键)：按住 Ctrl + 10px 边缘 8 方向智能缩放；按住 Ctrl + 内部拖拽自由平移；按住 Ctrl + 滚轮 ±8% 等比平滑缩放；Fluent 强调色辅助框与尺寸胶囊；右键标准网格尺寸一键预设菜单 已完成

2.4 桌面图标与格子模块 (LinBox)

  • 图标渲染缓存化 (RenderData Cache)：框选与移动卡顿大幅改善，仅在状态变化时局部重算 已完成
  • LinBox 容器化框架：支持 8 方向平滑缩放、标题栏编辑、背景颜色与透明度即时调整、毛玻璃效果 已完成
  • 文件夹映射 (Folder Portal)：实时监控物理文件夹并在 Box 内同步展示，拖入移出双向同步 已完成
  • 原生交互对齐：F2 重命名排除扩展名、外部文件双向拖入拖出 (QDrag/DropEvent)、空格键 QuickLook 快速预览、OCR 截图识别 已完成

2.5 桌面基础操作极速重构 (Basic Operations Performance)

  • 多图标拖拽单层幽灵图合并渲染：将 $N$ 个独立顶层 QLabel 窗口重构为单层合并 QPixmap 贴图，拖动窗口移动开销从 $O(N)$ 降低为 $O(1)$，彻底消除 Windows DWM 消息阻塞与微卡顿 已完成
  • 框选纯 QPainter 直绘与零残影局部重绘：彻底废弃 SelectArea 子控件树（m_fillWidget、m_borderWidget），直接在 ListView::paintEvent 与 LinBox::paintEvent 顶层绘制；采用联合脏矩形（Union Dirty Rect）更新，物理级根除残影 已完成
  • 局部绘制 QuadTree 空间索引裁切：在局部重绘时通过四叉树空间查询候选图标，并提供 32px 安全裕量，保证长文本标签与光晕完整呈现的同时削减 70%~90% 的全量扫描 CPU 开销 已完成
