2. 已完成事项

右键菜单

  • 桌面右键菜单完善：合并系统右键菜单和桌面自定义菜单 已完成
  • 菜单项功能点（View 大/中/小图标、Sort by 名称/大小/类型/日期、Refresh 刷新文件列表与图标布局、Paste / Paste shortcut 处理剪贴板文件流）已完成

桌面图标

  • 根据注册表值显示或隐藏系统图标 已完成
  • 图标交互增强：悬浮状态（半透明背景/阴影）、重命名（单击选中后再次单击或右键，弹出 QLineEdit 编辑）、物理同步（调用 Windows API 同步修改物理文件名）已完成
  • 拖拽与交互：外部拖出（QDrag 拖到文件夹或其他软件）、外部拖入（DropEvent 从资源管理器/浏览器拖入）已完成

监听模块

  • 文件夹监听：桌面文件夹内容变化同步 UI，文件系统新增/删除自动刷新 已完成
  • 注册表监听：按注册表信息显隐系统图标，注册表变化触发自动刷新 已完成
  • 壁纸监听：保持与系统壁纸一致，渐变切换壁纸效果 已完成

桌面格子模块

  • 基础框架：LinBox 继承 QWidget，标题栏 + 8 方向缩放手柄 + 内容区布局；图标模式 / 列表模式切换 已完成
  • 交互逻辑：右键菜单"新建桌面格子"入口；格子内自动排列、对齐网格；桌面图标拖入格子、格子图标拖回桌面；标题栏右键（置顶、重命名、更改颜色、删除格子）已完成
  • 数据持久化：data.json 存储 Geometry 与关联文件列表；启动反序列化加载；位置/大小变化实时保存 已完成
  • 小组件系统：CEF OSR 离屏渲染与统一层级架构（组件渲染在桌面图标下方；根除 UpdateLayeredWindowIndirect 报错；开关平滑切换）已完成

性能优化

  • 桌面图标 renderData 缓存化：拖拽选择和选择框移动卡顿大幅改善，paintEvent() 直接绘制缓存，renderData 仅在位置/图标尺寸/选中/hover/重命名/文本变化时重算 已完成
  • OpenGL 加速开关选项 已完成（实现待办，见第 1 节）

设置页面

  • UI 重新设计 已完成

文件快速预览

  • 快捷键响应：空格键触发预览 已完成
  • 预览窗口：无边框透明预览窗口，Esc 或再次按空格关闭 已完成
  • 文件预览支持：图片（QPixmap/QImage）、文本（QTextEdit）、视频/音频（QMediaPlayer）、PDF/Office（第三方组件）已完成

插件模块（OCR 截图文字识别）

  • 截图工具：置顶透明遮罩层、鼠标拖拽选区、双击确认截图 已完成
  • OCR 集成：集成 OCR 引擎（Tesseract / PaddleOCR / 百度 AI SDK 调研），异步识别防卡死 已完成
  • 结果展示：结果侧边栏支持文本编辑、一键复制 已完成
