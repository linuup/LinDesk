LinDesk 组件系统独立进程方案

读者：antigravity / 开发者 性质：架构改造任务书 范围：组件系统（linwidget + CEF OSR）从主程序分离为独立进程 更新：2026-10-13

1. 背景与目标

组件系统（HTML 小组件 + 壁纸）当前编译进主程序 LinDesk.exe，CEF（Chromium Embedded Framework）随主包分发。目标：组件系统独立为单独进程 LinWidgetHost.exe，用户按需下载组件包启用，主程序默认不携带 CEF 与组件代码。

  • 主程序瘦身：安装包不含 CEF（libcef.dll + Resources + 子进程约 150MB+），启动更轻、升级更快；
  • 按需启用：用户下载组件包 → 放入指定目录 → 主程序自动拉起 Host；未安装则组件入口隐藏、主程序功能完整；
  • 崩溃隔离：组件/CEF 崩溃只影响 Host 进程，主程序检测后自动重启 Host，桌面不崩；
  • 独立演进：组件系统独立仓库、独立版本、独立发布节奏，与主程序仅通过 IPC 协议通信（无 ABI 耦合）。
  • 主程序可脱离组件独立运行：组件为可选叠加层，未安装/停用时主程序桌面功能完整，安装与移除对主程序零影响。

3.1 核心设计决策：渲染与显示全在 Host 内

现有渲染链「OSR 帧 → 主程序 canvas 缓存 → ListView paintEvent 合成」中，帧缓冲只在主进程内流转。独立进程后若继续「OSR 帧 → 跨进程共享内存 → 主程序合成」，需要新写帧传输协议（共享内存 + dirty rect + 帧版本 + 同步），复杂度与性能损耗都高。

决策：不跨进程传帧。Host 进程内完成「CEF OSR 渲染 → 帧贴到自己的透明窗口」：

  • 组件 = Host 进程创建的透明无边框窗口（WS_EX_LAYERED 或普通透明 QWidget），frameReady 的 QImage 同进程直接 setPixmap/update（改动小：现有 frameReady → canvas 缓存 → paintEvent 的链路，改为 frameReady → 窗口缓冲区 → 窗口 paintEvent）；
  • 壁纸 = Host 进程全屏窗口（桌面底层 Z 序，图标之下），CEF 可直接窗口模式或 OSR 贴帧；
  • 主程序不参与渲染：删除 ListView canvas 合成调用（:1344/:1381）、LinWidgetCanvasWidget 迁入 Host。

3.2 窗口层级模型

  • 子窗口化：Host 的组件窗口 SetParent 到主程序桌面窗口（ListView 的 HWND，通过 IPC 下发 desktopLayerWindow），继承现有「组件在桌面画布内」的视觉语义（跟随移动/裁剪、Z 序由父窗口统一管）；
  • 穿透：组件窗口透明区域命中返回 HTTRANSPARENT（或手动命中测试转发），保证点击穿透到桌面图标层；
  • 壁纸层级：全屏窗口置于桌面图标层之下（与现有 desktopLayerWindow 语义对齐），非交互。

3.3 主程序无组件独立运行（硬保证）

「主程序在没有任何组件运行时的情况下完整可用」是架构约束，不是降级路径。三层保证：

层面保证
编译期linwidget/ 与 cef/ 不进主程序源列表；主程序不链接 CEF、不引用 WidgetManager 类型。主程序二进制不含任何组件代码，不存在「带组件的降级路径」——天生独立。
运行期启动时仅做一次 manifest 探测（<userDataDir>/runtime/linwidget/manifest.json），不存在 → 不拉起 Host、不建管道、不耗资源；组件相关 UI 入口（右键菜单项、设置页组件区）按 Host 在线状态动态显示。
行为期桌面/图标/格子/菜单/搜索/多显示器等核心功能零依赖组件系统；组件只是叠加层。移除组件包后主程序行为与安装前完全一致。

4. 通信协议（QLocalSocket 控制通道）

控制通道用 QLocalSocket（Windows 命名管道，进程内 Qt 直连，无网络栈）。不传输渲染帧、不逐事件转发输入，仅低频控制消息。

4.1 消息类型（JSON 信封）

方向消息载荷
主 → Hosthandshake协议版本、主程序版本、桌面窗口 HWND（desktopLayerWindow）
主 → Hostsync_layout组件几何/实例启停请求（launchWidgetPackage / stopWidget / move / resize 等价语义）
主 → Hostopen_settings请求 Host 弹出组件管理/设置窗口
主 → Hostping心跳（周期 5s），Host 回 pong；连续 3 次未回应 → 判死重启
Host → 主statusCEF 就绪/组件加载状态/错误（替代原 widgetError 信号）
Host → 主settings_requested组件请求打开设置（替代原 widgetSettingsRequested 信号）
Host → 主instance_event组件启停/崩溃事件（替代原 widgetLaunched/widgetStopped）

无 ABI 耦合：两进程不共享 Qt 对象、不跨进程传 QWidget*/信号槽，只交换 JSON + HWND 数值——主程序与 Host 可不同 Qt 版本、不同编译器、独立升级。

5. 生命周期管理

  • 启动：主程序启动延迟 100ms（沿用现有节奏）→ 检查组件包 manifest（runtime/linwidget/manifest.json）→ 存在则拉起 LinWidgetHost.exe --parent <pid> → 等待握手（超时 5s）→ 下发 desktopLayerWindow → 同步组件布局（registry.json 由 Host 自读，主程序只发"桌面就绪"通知）；
  • CEF 初始化：Host 进程内 WidgetManager 懒初始化逻辑保留（100ms 延迟策略不变），初始化完成后 status 上报；
  • 退出：主程序 aboutToQuit → 发 shutdown → 等 Host 优雅退出（2s 超时强杀）；Host 检测父进程退出（--parent PID 消失）自行退出（兜底）；
  • 崩溃重启：主程序监听 Host 进程退出 + 管道断开 → 区分正常退出/崩溃 → 自动重启 Host（5 分钟内最多 3 次，超限降级为「组件停用 + 提示」，避免崩溃风暴）；
  • 未安装：无 manifest → 不拉起、组件入口隐藏（右键菜单组件项、设置页组件区显示「下载组件运行时」）。

6. 数据与配置归属

  • 组件注册表 LinWidgets/registry.json、组件存储 LinWidgetsData/、壁纸 LinWallpapers/、配置 config.ini 中 LinWallpapers 段——全部由 Host 进程读写（同用户、路径规则复制到 Host 的 AppPaths 等价实现）；
  • 主程序不再读写组件数据，消除双进程并发写同一文件的隐患；
  • 权限隔离：Host 进程内 PermissionManager 继续按组件 manifest 控制网络/存储访问；Host 崩溃重启后权限状态从 registry.json 恢复。

7. 构建拆分清单

7.1 新工程 LinWidgetHost（独立仓库 / 独立 CMake）

  1. 迁移源文件：src/desktop/widgets/linwidget/*（业务层 13 个文件）+ src/desktop/widgets/cef/*（渲染层 5 个文件 + subprocess/main.cpp）；
  2. 目标：add_executable(LinWidgetHost WIN32 main.cpp ...)（Host 主程序：QLocalSocket 服务端 + WidgetManager 装配）+ add_executable(LinWidgetSubprocess WIN32 ...)（CEF 子进程，原 LinDeskSubprocess 更名迁入）；
  3. CEF 依赖：CEF 根目录/链接/资源拷贝逻辑从主工程搬入（原 CMakeLists:157-215 照搬）；
  4. Qt 依赖：Widgets/Core/Network/OpenGL/Svg/QuickWidgets/Concurrent（Host 不需要 WinExtras/Qml 全量）；
  5. 组件包产物：LinWidgetHost.exe + LinWidgetSubprocess.exe + cef/（libcef.dll、chrome_elf.dll、Resources 等全量）+ manifest.json → 打包 LinWidgetRuntime-vX.Y.Z.zip 发布 GitHub Releases。

7.2 主程序瘦身

  1. 删源：从 SOURCES 排除 linwidget/ + cef/（CMakeLists:117-138 加 FILTER 或改 glob 目录）；
  2. 删 CEF：CEF 条件编译块（:157-215）、CEF 链接、POST_BUILD 资源拷贝全部移除；
  3. 删渲染合成：ListView.cpp:1344-1345/:1381-1382 的 renderCanvas 调用删除（组件窗口由 Host 自行显示）；
  4. 删输入转发：ListView.cpp 中 forwardMouseEvent/forwardWheelEvent/forwardKeyEvent/forwardInputMethodEvent 调用点（10+ 处）删除，命中测试 isWidgetAt/widgetAt 改为基于 Host 上报的组件几何表（IPC instance_event 维护）；
  5. 删 CefManager：main.cpp:140 CefManager::shutdown() 移除；
  6. 新增 WidgetHostClient：QLocalSocket 客户端 + 进程拉起/监控/心跳 + 崩溃重启策略 + IPC 消息封装（替代 89 处 WidgetManager 直接调用中的交互类调用）。

8. 设置 UI 与用户启用流程

8.1 设置与 UI 迁移

  • 组件设置页（WidgetSettingsDialog + 开发工具）：整体迁入 Host 进程——组件管理窗口由 Host 自建（open_settings 触发），主程序设置页「组件」区只保留：状态/版本展示 + 「打开组件管理」按钮 + 「下载/安装组件运行时」引导；
  • 开发模式：DebugPanel 的组件开发入口（加载开发项目/重启）改由 Host 提供（同为 open_settings 通道下的独立窗口）；
  • 右键菜单：组件相关项（组件设置等）按「Host 是否在线」动态显示，命令经 IPC 转发。

8.2 下载方案

项设计
发布渠道GitHub Releases，资产 LinWidgetRuntime-vX.Y.Z.zip（组件系统独立仓库，与主程序发布节奏解耦）。
包结构LinWidgetRuntime/：LinWidgetHost.exe、LinWidgetSubprocess.exe、cef/（libcef.dll、chrome_elf.dll、icudtl.dat、Resources/、locales/、snapshot_blob.bin、v8_context_snapshot.bin 等 CEF 全量）、manifest.json（version、protocolVersion、qtVersion、abi、releaseNotes）。
安装位置<userDataDir>/runtime/linwidget/（与主程序探测点一致，同用户无权限问题）。
版本校验握手时校验 protocolVersion：不兼容 → 主程序提示「请更新组件运行时」并停用组件（不影响主程序本身）；manifest.version 展示在设置页。
更新方式设置页 [检查更新] → 打开 Releases → 下载新版 zip → 主程序通知 Host 退出 → 覆盖安装 runtime/linwidget/ → 重启 Host（或重启主程序后自动拉起）。

8.3 启用 / 停用 / 卸载（用户操作）

设置页新增「组件运行时」区，按安装状态展示：

  • 未安装：显示「未安装组件运行时」+ [下载] 按钮（打开 GitHub Releases 页）+ 说明：下载 zip 后解压到组件目录，重启 LinDesk 即自动启用；
  • 已安装：显示版本号 + [启用/停用] 开关（停用 = 写 enable=false 到运行时配置，之后不再拉起 Host、组件入口隐藏）+ [打开组件管理]（经 IPC 触发 Host 弹出组件管理窗口）+ [检查更新] + [卸载]（先停用，再删除 runtime/linwidget/ 目录）；
  • 默认行为：检测到 manifest 即自动启用，用户无需手动开启；
  • 手动兜底：不经设置页也可直接下载 zip 解压到组件目录 → 重启主程序即生效；删除目录 → 主程序不再拉起（即卸载）。

11. 边界（本次不做）

  • 壁纸组件实现：本方案只定架构（Host 全屏窗口），壁纸功能本体（视频/图片背景）仍按组件平台方案另立项；
  • 不引入第三方 IPC 库：QLocalSocket 足够，不引入 ZeroMQ/gRPC；
  • 不做跨进程拖拽共享：组件内拖拽在 Host 内完成；组件与桌面图标的跨区拖拽（如拖文件进组件）留待后续（需 drag&drop OLE 跨进程，成本高）；
  • 主程序不保留降级渲染路径：既然独立，主程序不再保留 canvas 合成代码（删除而非条件编译保留）。
