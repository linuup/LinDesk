LinWidget 协议与组件开发规范

版本：2.0.0（纯 Web 极简架构规范） 适用环境：Qt 5.15+ / CEF OSR Windowless 更新时间：2026-11-02 读者：前端开发者、组件创作者、底层架构师
小组件体系导航提示：本篇为极客开发规范与原生 API 接口速查手册。关于组件系统平台整体架构与路线规划，请参阅 组件平台方案；关于项目总体待办任务，请参阅 任务清单。

1. 核心架构与设计理念 (Architecture & Philosophy)

LinDesk 组件系统全面遵循“去过度设计、回归纯 Web 原生”原则：

  • 纯 Web 标准运行：数据持久化原生使用 localStorage / IndexedDB，网络请求原生使用 fetch / WebSocket，音视频与动画原生使用 HTML5 <video> 与 Canvas / WebGL。宿主绝对不造多余的私有存储与网络代理轮子。
  • Chromium 域隔离 (Origin Isolation)：每个组件与壁纸分配独立的自定义 Scheme（linwidget://<id>/），天然获得 Chromium 浏览器内核的独立本地存储配额与安全沙箱，不同组件间数据物理级隔离。
  • 三合一原生补足 (window.LinDesk)：宿主仅负责补足浏览器无法做到的系统级能力（硬件监控指标、安全资源管理器定位、窗口控制、壁纸工坊参数同步），全局挂载于 window.LinDesk。
  • 零 C++ 编译负担：创作者在任意现代浏览器（Chrome/Edge）中即可双击 index.html 编写调试，放入 LinDesk 即热加载生效。

2. 组件包规范与 Manifest 规范 (Package & Manifest)

小组件与壁纸统一采用 .lw 格式（标准 zip 压缩包，开发期可直接以同名明文文件夹存在）。包根目录下必须包含 manifest.json：

2.1 目录结构与分流规则

MyCoolPackage/
├── manifest.json       # 元数据（必须）
├── icon.png            # 预览图标（推荐 128x128 PNG）
├── index.html          # 入口 HTML 页面（必须）
├── style.css           # 样式表
└── script.js           # 逻辑脚本

智能分流约定：安装器解压前读取 manifest.json 中的 type 字段：

  • "type": "widget" → 自动分流解压归档至 LinWidgets/<id>/ 目录（小组件）；
  • "type": "wallpaper" → 自动分流解压归档至 Wallpapers/<id>/ 目录（动态壁纸）。

2.2 manifest.json 规范示例

小组件规范 (type="widget")：

{
  "id": "lindesk.cyber.clock",
  "name": "赛博时钟",
  "type": "widget",
  "version": "1.0.0",
  "entry": "index.html",
  "defaultSize": { "width": 360, "height": 180 },
  "minSize": { "width": 200, "height": 100 },
  "maxSize": { "width": 800, "height": 600 }
}

动态壁纸规范 (type="wallpaper")：

{
  "id": "lindesk.wallpaper.gargantua",
  "name": "卡冈图雅引力黑洞",
  "type": "wallpaper",
  "wallpaperType": "web",
  "interactive": true,
  "version": "1.0.0",
  "entry": "index.html",
  "properties": {
    "speed": { "type": "slider", "text": "旋转速度", "value": 5 }
  }
}

核心字段说明

字段类型必填默认值说明
idstring是-全局唯一标识（小写字母、数字、点号与中划线）
namestring是-展示名称
typestring是"widget"大类分类："widget"（小组件）或 "wallpaper"（动态壁纸）
wallpaperTypestring否"web"壁纸媒介格式（仅 type="wallpaper"）："web"（Canvas/WebGL/Shader）、"video"（MP4/WebM 视频）、"picture"（高清静态大图）
interactiveboolean否false桌面鼠标交互开关（仅 type="wallpaper"）：true 启用粒子引力/波纹物理交互并接入 6px 曼哈顿框选仲裁；false 100% 鼠标无感穿透
versionstring是"1.0.0"版本号
entrystring否"index.html"入口文件相对路径
authorstring否-作者信息
defaultSizeobject否{ width: 320, height: 200 }初始宽高（仅 type="widget" 生效）
minSize / maxSizeobject否-边缘缩放最小/最大宽高限制（仅 type="widget" 生效）
propertiesobject否{}声明式用户调节参数（仅 type="wallpaper" 生效，对标 Wallpaper Engine 标准，工坊自动据此生成滑块/取色器）

2.3 壁纸正交分类矩阵 (Orthogonal Matrix)

wallpaperTypeinteractive壁纸语义与典型体验工坊画廊标签宿主鼠标处理与性能策略
"web" true 互动式 Web 动态壁纸（引力粒子、水波波纹、3D 视差倾斜、可点击切换场景） 🎮 Web 交互 开启 60FPS MouseMove 广播；原地点击交付壁纸，拖拽 ≥ 6px 交付桌面多选框选；工坊提供「启用鼠标互动」用户开关
"web" false 展示型 Web 动态壁纸（纯 Shader 极光流体、数字雨、动态时钟景观） 🌐 Web 动效 切断鼠标移动广播（降低 CPU/GPU 消息开销）；鼠标事件 100% 穿透交付桌面
"video" false 视频壁纸（4K 循环视频、影视实拍、二次元动效短片） 🎬 循环视频 纯流媒体播放；100% 鼠标穿透；工坊自动呈现「视频音量、循环、倍速」控制卡片
"picture" false 超高清大图壁纸（4K/8K 摄影、插画） 🖼️ 静态大图 轻量 CSS 渲染；100% 鼠标穿透；工坊呈现「暗度遮罩、毛玻璃高斯模糊」滤镜卡片

3. window.LinDesk 原生系统能力速查 (Native API Reference)

宿主通过 CEF 离屏渲染管道向组件网页全局注入 window.LinDesk 对象。所有方法均采用现代 Promise 与事件监听接口风格。

3.1 系统硬件监控 (LinDesk.system)

用于开发仪表盘、悬浮球、硬件监控类小组件。

3.1.1 异步获取硬件快照 getMetrics()

window.LinDesk.system.getMetrics().then(function(metrics) {
  console.log("CPU 占用:", metrics.cpu + "%");
  console.log("已用内存:", metrics.memory.usedMB + " MB / " + metrics.memory.totalMB + " MB");
  console.log("当前电量:", metrics.battery + "%");
  console.log("网络速率:", metrics.network.downSpeed + " KB/s");
});

3.1.2 订阅周期推送 onMetrics(callback)

宿主每隔 1000ms 采样并派发最新数据。组件被隐藏或全屏独占休眠时自动挂起推送。

// 开始监听并保存退订句柄
const unlisten = window.LinDesk.system.onMetrics(function(metrics) {
  document.getElementById("cpu-val").innerText = metrics.cpu + "%";
});

// 适时取消监听
// unlisten();

3.2 原生定位与外链 (LinDesk.shell)

用于便签、快捷启动板、常用目录跳转类小组件。

3.2.1 资源管理器安全定位 openPath(filePath)

在 Windows 资源管理器中打开指定目录或高亮选中文件。

window.LinDesk.shell.openPath("C:\\Users\\Desktop").then(function(success) {
  if (!success) console.error("路径不存在或被安全策略拦截");
});
物理级硬拦截约束：为防止恶意组件，openPath 物理级禁止唤起任何二进制可执行程序（.exe, .bat, .cmd, .ps1, .vbs, .msi 等）。传入此类目标直接被拒绝并返回 false。

3.2.2 系统浏览器打开外链 openUrl(url)

调用系统默认外部浏览器打开指定网页链接。

window.LinDesk.shell.openUrl("https://github.com").catch(function(err) {
  console.error("打开链接失败:", err);
});

协议限制：仅允许标准 http:// 与 https:// 协议，拦截其他敏感 URI Scheme。

3.3 容器控制 (LinDesk.widget)

仅对小组件（type="widget"）生效。

// 关闭并隐藏当前组件
window.LinDesk.widget.close();

// 唤起 LinDesk 主设置窗口并跳转到当前组件的管理面板
window.LinDesk.widget.openSettings();

3.4 壁纸工坊参数监听与媒体加载 (LinDesk.wallpaper)

仅对动态壁纸（type="wallpaper"）生效。当用户在壁纸工坊 (LinDesk Hub) 中拖动滑块、修改调色盘或拨动开关时实时触发：

window.LinDesk.wallpaper.onPropertyChange(function(prop) {
  console.log("参数变动:", prop.key, "新数值:", prop.value);
  if (prop.key === "speed") {
    particleEngine.setSpeed(prop.value);
  } else if (prop.key === "glowColor") {
    particleEngine.setGlowColor(prop.value);
  }
});

视频壁纸媒体流式加载：

  • 包内相对视频直接引用：<video src="bg.mp4" autoplay loop muted>；
  • 用户外部导入大文件视频引用：<video src="linwidget://media?path=D%3A%2FMyWallpapers%2Fmovie.mp4" autoplay loop>。

4. 安全沙箱与防护体系 (Security & Sandbox)

  • 壁纸 API 调用隔离：壁纸运行沙箱中严格禁用 LinDesk.widget 容器操作（如 close()），防止壁纸误调导致桌面背景异常黑屏；
  • 60FPS / 30FPS 渲染帧率锁：宿主对 CEF OSR 强制锁定最高 60FPS（或省电模式 30FPS），严禁 WebGL 跑满 GPU 造成笔记本发热降频；
  • 本地资源隔离 (linwidget://)：组件静态资源仅限在各自包目录内加载。资源加载器强制规范化路径，严格阻断 ../../ 穿越路径，禁止跨包越权访问磁盘；
  • 物理级执行拦截：LinDesk.shell.openPath 严禁执行一切外部二进制程序，切断木马与勒索病毒的静默启动途径；
  • 全屏独占智能休眠：当系统前台运行独占 3D 游戏或全屏视频时，宿主自动暂停 OSR 离屏渲染循环与周期推送，实现 0.0% CPU/GPU 零开销；
  • 透明区域鼠标穿透：小组件未绘制内容的透明区域（Alpha < 10）自动将鼠标事件穿透回桌面底层，确保原生桌面图标框选与点击体验丝滑无阻。

5. 创作者极客开发流 (Developer Workflow)

  1. 本地零依赖开发：在本地新建文件夹并创建 index.html 和 manifest.json，直接在 Chrome/Edge 浏览器中双击打开调试排版；
  2. 丢入即热重载：将文件夹放入 LinDesk 的 LinWidgets/ 或 Wallpapers/ 目录，LinDesk 运行时自动识别载入；
  3. 呼出 F12 调试：桌面右键组件选择呼出 Chromium F12 DevTools 控制台；修改本地 HTML/JS 代码后按 Ctrl+R 即时热刷新。
