LinDesk 模块介绍文档

版本：1.0.8 Stable 技术栈：Qt 5 / C++20 / CMake + vcpkg 平台：Windows x64 整理日期：2026-10-12

1. 项目概览

LinDesk 是一款 Windows 桌面整理软件（对标腾讯桌面整理、Codesker），用于桌面图标管理、分类整理、批量操作与个性化桌面管理。主体代码位于 src/，由单个 CMake 工程统一构建，另含更新模块、Win11 右键菜单宿主与 OCR 插件等配套工程。

工程要点：

  • 版本号单一来源：CMakeLists.txt 中 LINDESK_VERSION_* 定义，通过 configure_file 生成 src/app/Version.h、LinDesk.rc 与安装脚本。
  • 依赖管理：vcpkg（vcpkg.json），Qt5 组件包括 Widgets、WinExtras、Core、Network、OpenGL、Svg、Qml、Quick、QuickWidgets、Multimedia、LinguistTools。
  • CEF（Chromium Embedded Framework）为可选集成：3rdparty/cef 存在时启用 LINDESK_HAS_CEF 并构建 OSR 子进程；WebView2 同样按目录探测启用。
  • 多语言：translations/ 下维护 lindesk_zh_CN.ts、lindesk_en_US.ts，构建时经 Qt Linguist 编译为 .qm 并拷贝到输出目录。

3. 模块划分

src/ 下共 10 个模块目录，其中 desktop 内嵌 widgets/linwidget 与 widgets/cef 两个子系统。

3.1 app —— 应用入口与全局配置

主窗口与应用级配置。主程序入口由 LinDesk 主窗口承载，启动时加载字体、语言与启动参数。

关键类职责
LinDesk主窗口（单例），处理桌面右键菜单事件，作为整体 UI 根容器
AppFonts应用字体加载与管理
AppLaunchOptions启动命令行参数解析
LanguageManager语言/多语言切换，配合 translations 目录
Version版本号定义（由 CMake 生成）

3.2 desktop —— 桌面画布与图标管理（核心模块）

桌面整理的核心：负责图标列表渲染、框选、拖拽、重命名、右键菜单等交互。分层结构与 Readme.md 描述一致：ListView（图标项）→ SelectArea（框选层）→ LinDesktop（控制层）。组件渲染走统一绘制管线（壁纸 → CEF OSR 组件画布 → 图标层），详见 架构指南。

关键类职责
LinDesktop桌面画布根控件：组合 ListView、SelectArea、组件画布、桌面监控，处理鼠标事件与透明度过渡
ListView图标列表视图，绘制每个列表项（图标、覆盖层、文件名）
SelectArea拖拽框选区域，绘制选择框，支持多选/单选
ListViewModel / DesktopRootItemModel列表与桌面根项的数据模型
DesktopRootItemState / DesktopRootItemRenderData桌面根项的状态与渲染数据
DesktopItemRenderCacheHelper图标项渲染缓存，提升重绘性能
ListViewDragDropHelper图标拖拽逻辑（拖入盒子、分类等）
ListViewFileOpsHelper文件级操作（移动、删除等）
ListViewMappedBoxHelper图标映射到盒子的归属逻辑
ListViewSelectionController / ListViewSelectionHelper / ListViewSelectionSnapshot多选状态控制、辅助与快照
ListViewDebugPanel列表调试面板
RightMenu右键快捷菜单
RenameManager / FilenameEditor图标重命名管理与内联编辑框
DesktopSnakeGame桌面小游戏（贪吃蛇）
Win11MenuBridge与 Win11 右键菜单宿主（Win11MenuIsland）通信

3.2.1 desktop/widgets/linwidget —— LinWidget 桌面小组件系统

桌面小组件（Widget）与动态壁纸的运行时：组件包加载、组件运行时（当前主渲染为 CEF OSR，WebView2 运行时待移除）、配置/布局/权限管理。架构细节见 架构指南。

关键类职责
WidgetManager组件总控：启动组件、动态壁纸（startWallpaper）、配置读写、层级同步
LinWidgetWebViewRuntime小组件的 WebView 运行时（待移除，当前主渲染为 CEF）
LinWallpaperWebViewRuntime动态壁纸的 WebView 运行时（CEF 无替代，去留待决策）
WidgetPackage组件包（描述、资源）
ConfigManager / LayoutManager / PermissionManager组件配置、布局与权限管理
WidgetRegistryManager组件注册表管理
WidgetSettingsDialog组件设置对话框
WidgetMessageTypes / LinWidgetTypes组件消息与类型定义
LinWidgetProjectTools组件开发辅助工具

3.2.2 desktop/widgets/cef —— CEF OSR 渲染集成

基于 Chromium Embedded Framework 的离屏渲染（OSR）集成，为 LinWidget 提供浏览器内核渲染能力。

关键类职责
CefManagerCEF 生命周期与全局初始化管理
CefOsrBrowserInstanceOSR 浏览器实例（单组件对应实例）
CefOsrRenderHandler离屏渲染回调处理
LinWidgetCanvasWidget组件画布控件，承载 OSR 内容显示

3.3 box —— 桌面盒子

可折叠的盒子容器，把桌面图标按文件夹/分类收纳组织，支持图标、列表两种显示模式。

关键类职责
LinBox盒子控件：图标/列表两种显示模式、折叠、拖拽落点预览、内联重命名、映射文件夹状态（正常/缺失/无权限）
BoxManager盒子生命周期管理（创建/销毁/查找/置顶）、布局与图标归属持久化（saveAll/loadAll）、文件归属查询

3.4 models —— 数据模型

与桌面/文件相关的数据模型与空间结构。

关键类职责
DeskFileModel桌面文件数据模型（名称、路径、图标路径）
DesktopQuadTree桌面图标空间四叉树，用于布局/碰撞检测
data/ListItemData列表项数据定义

3.5 monitor —— 文件系统与配置监控

监听系统级事件：桌面文件变化、Windows 配置变化、桌面信息变化，并转换为应用内事件。

关键类职责
DirectoryMonitor / LinDirectoryMonitor基于 Windows SHChangeNotify 的文件系统事件监听（创建/删除/重命名/属性变化/驱动器变化等）
WindowsConfigMonitorWindows 配置/注册表变化监听
DesktopInfoMonitor桌面信息监控
IDirectoryMonitorInterface / IListenerInterface / IRegistryListenerInterface监听器抽象接口

3.6 services —— 服务层

跨模块的基础能力：Windows 系统集成、系统信息、更新、持久化、热键、图标缓存、日志、崩溃处理等。

关键类 / 子目录职责
SystemApi/Windows 系统集成：SystemApi、ShellContextMenu（Shell 右键菜单）、MenuHelper、ResourceHelper、WindowSubclassWrapper 及枚举/类型定义
SystemInfo/SystemInfoService系统信息采集（CPU / GPU / 内存，基于 Iphlpapi、Dxgi、Pdh）
update/更新模块：UpdateChecker（版本检查/比较）、UpdateDownloader（下载）、UpdateTypes（数据结构）
HotkeyManager全局快捷键注册与管理
IconCacheManager图标缓存，避免重复提取系统图标
LayoutPersistenceService桌面布局与盒子状态持久化（收集/保存/加载图标位置与显示规则）
DesktopItemLoader桌面图标加载
DpiCoordinateHelper / DpiScaleHelperDPI 坐标换算与缩放适配
LogManager日志管理
CrashHandler / DebugInfoExporter崩溃处理与调试信息导出
AppPaths / SysInfoUtil应用路径与系统信息工具
LinDeskHoveredItemServer / SpaceLookIpcClient悬停项服务与 SpaceLook IPC 客户端
ShellMenuExclusionStoreShell 菜单排除项存储
WinBlurHelper窗口模糊特效辅助

3.7 plugins —— 插件体系

基于 Qt 插件机制的动态库扩展体系，提供插件生命周期与能力接口。

关键类职责
ILinPlugin插件基接口：标识（pluginId/pluginName/pluginDescription）、生命周期（onInit/onUnload/onSettingsRequested/onTrigger）、可选自定义热键（customHotkey）
IOCRPluginOCR 能力扩展接口（recognizeText）
PluginManager插件发现与加载（DLL）、热键注册、启用状态管理、按 ID 触发插件

现网插件：Plugins/OCRModule 为默认构建的 OCR 插件（LINDESK_BUILD_OCR_PLUGIN，默认 ON）。

3.8 ai —— AI 对话能力

多厂商大模型对话能力：统一的客户端抽象、请求管理与后台工作线程。

关键类职责
AIClient客户端入口与 ProviderKind 提供商枚举
client/AIProviderBase 及实现提供商抽象基类与实现：OpenAI、Claude、Google、Ollama 客户端
AICoreService核心服务：provider 切换、消息发送/流式回复/取消/超时，工作线程模型
AIWorker后台工作线程，执行网络请求
AIRequestManager请求管理

3.9 ui —— 界面控件与设置

Fluent 风格控件库、设置界面与桌面文字预览渲染。

关键类 / 子目录职责
Fluent/Fluent 风格控件库：FluentBaseWidget、FluentBaseDialog、FluentDialog、FluentButton、FluentCard、FluentCheckBox、FluentColorWheel、FluentComboBox、FluentDragTip、FluentInfoTip、FluentInput、FluentResultView、FluentToggleSwitch、FluentWidget
SettingUI设置主界面：常规设置、盒子/组件配置、更新检查与下载等入口
SoftDesktopTextRenderer桌面文字渲染与描边/发光效果
QmlTestWindowQML 测试窗口

3.10 resources —— 应用资源

图标、样式等应用资源（.qrc 打包，构建后拷贝到输出目录 resources/）。

4. 模块依赖关系

app（入口 / 主窗口）
└─ 加载与组合
desktop（桌面画布 + 图标管理）└─ widgets/linwidget ─ widgets/cef
│ ├─ 收纳box（盒子）
│ ├─ 使用models（数据模型）
│ ├─ 依赖services（系统集成/持久化/热键/更新…）
│ ├─ 订阅事件monitor（文件/配置监控）
│ ├─ 扩展plugins（插件）
│ └─ 使用ui（Fluent 控件 + 设置界面）
└─ 独立能力ai（AI 对话）

说明：app 为入口；desktop 依赖 box、models、services、monitor、plugins、ui；monitor 将系统事件转换为应用事件供桌面层消费；services 提供跨模块公共服务；ai 相对独立。以上为代码层面的模块归属关系，不表示严格分层架构。

5. 构建与测试

构建目标类型说明
LinDesk可执行文件主程序，glob 收集 src/ 下 cpp/h/qrc（排除旧 ListItem 与 subprocess），链接 Shell32、Psapi、Qt5 等
LinDeskUpdate子工程更新模块（LinDeskUpdate/），主程序依赖它
LinDeskSubprocess可执行文件CEF 子进程（仅 CEF 存在时构建）
Win11MenuIsland可执行文件Win11 右键菜单宿主，Visual Studio 生成器下通过 include_external_msproject 引入
LinDeskSystemInfoTests测试可执行文件SystemInfo 服务单元测试（GTest），注册为 CTest 用例
OCRModule插件动态库OCR 插件（Plugins/OCRModule，默认构建）
translations自定义目标ts → qm 编译并拷贝到输出目录

构建流程：vcpkg install --triplet x64-windows → cmake -B build → 用 VS2022 打开 build 目录构建运行。Debug 配置显示控制台，Release 配置隐藏（WIN32_EXECUTABLE）。
