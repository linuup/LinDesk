1. 建议的阅读路径

按读者角色进入对应文档：

  • 不了解 LinDesk 是什么 → 产品介绍（定位、功能、技术栈）。
  • 要了解代码结构与模块职责 → 模块介绍（src 下各模块职责、依赖、构建目标）。
  • 要理解渲染与组件系统架构 → 架构指南（CEF OSR 版，统一绘制管线）。
  • 要查功能进度与待办 → 任务清单（由项目根 Todo.md 迁移整理）。
  • 要打磨 HTML 组件系统（AI 开发组件、组件市场、权限/沙箱、组件包动态加载、组件系统安装/卸载） → 组件系统方案（单进程 · 组件系统运行时经 LinDesk 安装/卸载 + 组件包动态加载：安装/卸载设计、CEF 缺口、AI 开发闭环、与主程序集成、按代码细分的任务清单、P0-P3 路线图）。
  • 要发布 32/64 位安装包或排查"启动报 Qt 入口点错误" → 双架构发布方案（x86 + x64 构建/部署/打包/发布/更新器全链路改造：CEF win32 引入、windeployqt 部署、Inno 参数化、按位数匹配资产，含 T0-T7 任务清单）。
  • 要排查桌面图标缓存无限增长 / ListView 内存问题 → ListView 内存审查（图标缓存只增不减根因 + T1-T7 修复任务清单）。
  • 要处理微软商店（UWP/MSIX）应用图标显示为白色或通用图标 → 商店应用图标兼容（IShellItemImageFactory 主路径 + AUMID/AppxManifest 兜底，T1-T5 任务清单）。
