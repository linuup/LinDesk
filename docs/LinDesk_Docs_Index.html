1. 建议的阅读路径

按读者角色进入对应文档：

  • 不了解 LinDesk 是什么 → 产品介绍（定位、功能、技术栈与形态）。
  • 要了解代码结构与模块职责 → 模块介绍（src 下各模块职责、关键类、依赖关系、构建目标）。
  • 要理解渲染与底座系统架构 → 架构指南（CEF OSR 版统一绘制管线、WorkerW 嵌入、持久化数据流）。
  • 要查全局任务进度与待办 → 任务清单（单一真实来源：冷启动、右键菜单、小组件与核心体验全景任务）。
  • 要深入小组件系统 (LinWidget)：
    • 平台架构与生态规划 → 组件平台方案（单进程动态加载、市场分发、沙箱安全）
    • 管理界面与桌面交互重构 → 组件管理与交互（HTML/SPA 化、消灭壁纸框选冲突、智能手柄）
    • 开发手册与通信协议字典 → 组件通信协议（Manifest 规范、Bridge 双向 IPC、API 字典）
  • 要优化桌面基础核心功能人机工学交互与动效质感 → 核心功能体验优化方案（LinBox 缓动折叠、悬停下卷展开、磁吸对齐、盲打跳选、Ctrl+Z 撤销、淡入淡出、一键智能整理）。
