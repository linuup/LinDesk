1. 建议的阅读路径

按读者角色进入对应文档：

  • 不了解 LinDesk 是什么 → 产品介绍（定位、功能、技术栈与形态）。
  • 要了解代码结构与模块职责 → 模块介绍（src 下各模块职责、关键类、依赖关系、构建目标）。
  • 要理解渲染与底座系统架构 → 架构指南（CEF OSR 版统一绘制管线、WorkerW 嵌入、持久化数据流）。
  • 要查全局任务进度与待办 → 任务清单（单一真实来源：底座冷启动、右键菜单、核心人机工学体验与小组件全景待办）。
  • 要深入小组件系统 (LinWidget)：
    • 平台架构与交互体系 → 组件平台方案（单进程动态加载、三层交互仲裁、Ctrl 尺寸缩放体系、市场与沙箱）
    • 开发手册与通信协议字典 → 组件通信协议（Manifest 规范、Bridge 双向 IPC、API 字典）
