## LinDesk 2.0.0 里程碑大版本发布 🎉

LinDesk 迎来了 2.0.0 重大里程碑！本次更新对底层架构、前端控制中心、动态壁纸工坊及离线智能服务进行了全方位的深度革新。

### 🌟 核心更新亮点

#### 1. 纯代码 Canvas 2D 手绘动态壁纸《清风原野 · 晨曦自然》
- 摒弃厚重的外部媒体，采用纯原生 Canvas 2D 代码绘制自然晨曦原野。
- 支持晨曦/正午/黄昏/深夜 24 小时昼夜平滑过渡、风力扰动算法带动花草摇曳、微风蒲公英孢子与流星划破夜空。
- 0 外部资源加载，内存与 GPU 占用极度轻量。

#### 2. 现代 Web 前端调度中心与壁纸工坊 (LinDesk Hub & Wallpaper Studio)
- 基于 shadcn/ui + React + TailwindCSS 重塑现代桌面中枢。
- Master-Detail 壁纸工坊：支持本地与网络壁纸的一键导入、16:9 实时物理画板与动态桌面图标模拟预览。
- 视觉与播放控制升级：提供 0%~100% 连续可调的高级感知多尺度背景模糊度，普通视频与壁纸全面常驻平铺展开。
- 宿主通用外挂面板：动态解析壁纸作者参数与底座通用调控项。

#### 3. 离线/本地 OCR 智能文字识别引擎
- 深度集成 ONNXRuntime 与 PP-OCRv6 轻量模型。
- 支持全离线运行，无需连网，无第三方 API 密钥门槛。
- 多线程异步识别流水线，毫秒级响应，全面守护用户隐私。

#### 4. 底座架构解耦与能效状态机
- 完成了对 `ListView`、`WidgetManager`、`LinBox` 等模块的全面解耦重构。
- 接入 GPLv3 许可证与安全多进程沙箱体系。
- 智能能效状态机：全屏游戏/3D 窗口自动 0.0% 挂起休眠，交流电/电池自适应动态帧率。
