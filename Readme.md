# LinDesk · 桌面整理与美化工具

LinDesk 是一款为 Windows 打造的桌面整理与美化工具。帮助你告别凌乱的桌面，让桌面既整洁有序，又赏心悦目。

---

## ✨ 核心功能

### 📦 桌面收纳盒
* **随心分类**：把散落的桌面图标、文件、文件夹整齐归类到不同的收纳盒中。
* **灵活折叠**：支持一键折叠收拢，让桌面瞬间清爽。
* **个性外观**：自由调整收纳盒的主题颜色、透明度和摆放位置。
* **一键隐藏**：双击桌面空白处即可隐藏或显示所有桌面内容，随时切换专注状态。

### 🎨 动态壁纸工坊
* **丰富壁纸类型**：支持高清视频壁纸、动态互动壁纸与精美静态壁纸。
* **随心微调**：内置壁纸工坊，可自由调节壁纸亮度、背景模糊效果以及播放速度。
* **省电安静**：在全屏玩游戏或办公时会自动暂停壁纸播放，轻巧流畅不卡顿。

### 🧩 实用桌面小组件
内置多款轻便好看的桌面小工具，无需打开软件即可在桌面上随时查看：
* **时钟与倒计时**：极简时间显示，工作学习更专注；
* **实时天气**：随时掌握今天与近期的天气变化；
* **便签与待办**：灵感随时记录，待办事项一目了然；
* **系统状态**：实时查看电脑运行负荷；
* **饮水与健康**：贴心的日常习惯提醒。

### 💡 贴心辅助工具
* **截屏识字**：一键截取屏幕区域，自动提取图片中的文字并复制。
* **原生视觉体验**：采用 Windows 现代浅色与微透明玻璃质感设计，自然融入系统。

## 💻 系统支持

* 支持 Windows 10 及 Windows 11
* 支持高分辨率屏幕，显示清晰细腻
