请帮我实现一个基于 HTML、CSS 和 JavaScript 的“倒计时（Timer）小组件”。要求完全复刻我提供的原生 Qt 组件的视觉设计和功能，采用高级的毛玻璃（Glassmorphism）和 Fluent UI 风格。
#### 1. 核心状态与颜色主题
倒计时共有 4 种状态，每种状态对应不同的强调色（Accent Color）和状态文本：
- **Ready (未开始)**：深灰蓝色 `#4A5E78`，文本显示 "Ready"
- **Running (运行中)**：主题蓝色 `#0078D4`，文本显示 "Running"
- **Paused (已暂停)**：琥珀橙色 `#D97706`，文本显示 "Paused"
- **Done (已完成)**：危险红色 `#DC2626`，文本显示 "Done"
*时间格式始终保持 `MM:SS` (如 05:00)。*
#### 2. 三种响应式布局模式（通过 CSS Media Queries 实现）
组件需要根据容器的大小自动切换以下三种模式：
1. **Mini 模式 (胶囊状)**：水平极简布局。左侧是一个状态呼吸点，右侧是加粗的时间文本（没有状态文字），整体呈现胶囊形状（高度的一半为圆角）。
2. **Card 模式 (常规卡片)**：圆角矩形。时间文本居中且字号较大；左下角是状态呼吸点，呼吸点右侧跟随状态文本。
3. **Expanded 模式 (大屏展开)**：大尺寸圆角矩形。背景中心有一个对应强调色的微弱半透明大圆圈作为点缀。中心是巨大的时间文本，左下角是呼吸点和状态文本。
#### 3. Fluent UI 视觉风格
背景卡片需要实现类似 Windows Fluent Design 的质感：
- **背景填充**：从左上到右下的半透明白色到微蓝色的线性渐变，并带有强烈的背景模糊（`backdrop-filter: blur`）。
- **状态渲染 (Tint)**：卡片的左下角需要叠加一层对应状态强调色（Accent Color）的微弱渐变光晕。
- **边框与高光**：1px 的边框，左侧和顶部为半透明白色（模拟高光），右侧和底部为极淡的深色（模拟阴影），营造 3D 浮雕感。
- **阴影**：多层柔和的弥散阴影，使卡片悬浮感自然。
#### 4. 动画要求：状态呼吸点 (Breathing Dot)
这是一个极其关键的视觉元素，需要用 CSS 动画实现：
- 基础形态是一个带有内部高光的小圆点。
- 在 **Ready** 状态下只有微弱的慢速透明度呼吸。
- 在 **Running**、**Paused** 和 **Done** 状态下，圆点需要不断向外发出两个波纹圆环（Ripple 动画），并且有更强烈的光晕（Glow）闪烁。
- 动画的剧烈程度：Done 状态最强烈，Running 其次，Paused 较平缓。
#### 5. 交互要求
- 点击组件任意区域可切换状态（如：Ready -> 点击开始 -> Running -> 点击暂停 -> Paused -> 点击继续 -> Running... 时间到则变为 Done）。
- 实现基础的倒计时 JS 逻辑，每秒更新 DOM 中的时间显示和对应状态的 CSS class。
